Usage: miyu check [file] [options]

Look for mistakes in the files you write by hand: the system config, your
personal settings, the project config here, the secrets file, and
persona.toml and prompts/examples.md in each persona directory. Each one
is printed with its file, line, what is wrong and how to fix it. The exit
code is 1 when there are errors.

With a file, only that file is checked.

Options:
      --format text|json  text for people (default), json for scripts
  -h, --help              Print help

Examples:
  miyu check
  miyu check ~/.miyu/home/admin/personas/miyu/prompts/examples.md
