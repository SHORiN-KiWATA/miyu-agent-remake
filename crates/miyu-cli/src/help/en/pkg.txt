Usage: miyu pkg [command] [options]

See which packages are installed; install, remove.
Without a command it is list.

Commands:
  list                    List packages
  install <manifest|id>   Install a manifest (path to <id>.toml), or bring back a removed shipped one
  remove <id>             Remove a package

Options:
      --format text|json  list: json for scripts
  -h, --help              Print help
