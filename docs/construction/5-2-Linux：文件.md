## 施工单 5-2：Linux：文件

状态：施工中（2026-09-28）。

### 目的

Linux 上，助手照规格用 Landlock 收紧自己：规格里放行的读得了、写得了，别的一律碰不到，命令起的子进程也一样。探测时报 `landlock`。

### 蓝图改哪几节

- 新的一页 `sandbox/linux.md`：规格的每一格 Landlock 怎么放、收不住的怎么办、探测报什么；蓝图 README 的分页表加这一行。
- `sandbox.md`：「还没有的」里 Linux 那一条去掉 Landlock。

### 不做什么

- 只读的、藏起来的落在放行的范围里：Landlock 挖不掉，这一步拒绝执行，5-3 用挂载命名空间补上。
- 网络：5-6。
- 核心还不给调用带规格；默认放行的清单（系统目录、`/dev/null`、沙盒自己的工具链缓存）随 5-4。

### 验收

只有技术细节，照施工方案第一节第 1 条直接做：

1. 真跑助手（本机 Arch，内核 7.2）：规格里的读得了、写得了；规格外的读不了、写不了、执行不了，命令起的子进程一样；只读目录里写不了；只读的、藏起来的落在放行范围里，拒绝执行；探测报 `landlock`。
2. 手写的变异全被测试逮住。
3. `cargo xtask check` 八项全过；三台机器的 CI 全绿，Ubuntu 那台也真跑 Landlock。

### 风险

- 内核：设计支持的最老是 6.8，Landlock 默认开着；关了的机器探测报空，助手收到规格就拒绝执行，5-4 照「沙盒用不了」办。
- 程序要读的系统文件不在规格里就会失败：放行清单由 5-4 定，这一步的测试给一份够 `sh`、`cat` 用的。
