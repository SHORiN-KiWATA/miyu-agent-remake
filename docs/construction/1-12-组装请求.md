- 环境和状态的事实（时间、工作目录、权限级别，变了才注入）：1-13。
- 读资源文件：内核和第 2 层是纯逻辑，不读文件。出厂的英文由执行器读好交进来（M3）；测试用 `include_str!` 在编译时拿。

- 角色扮演提示排在触发消息之后：等有了角色扮演提示再加（`26-提示词.md` J10）。

### 要拍板的

1. **出厂的那几句英文**，就是 `resources/core/` 下的七个文件。
   - 回合没走完的四句：被人打断、出了错、走到步数上限、程序重启没走完。只说发生了什么，不说该怎么做（`26-提示词.md` J2）。定了：照写的（2026-09-26 项目主人：「turn ended的提示没问题」）。
   - 检查点：项目主人要我先看 Claude Code 和旧版是怎么拼的（「你可以看一下claudecode或旧miyu的compact的提示是怎么组装的」）。
     - Claude Code：读的是本机 2.1.280 的二进制，拿本机 176 次压缩的转录核对过。压完是一条 user 消息，没有标签外壳。开头说这个会话是从一次上下文用尽的对话接着来的，然后是摘要、完整转录的路径，末尾一句「接着做，别再问用户，不要确认或复述摘要，就像没断过一样」。自动压缩、手动压缩都带这一句（176 次全带：自动 168 次、手动 8 次），只有局部压缩不带。它的 system 里另有常驻的一句，说快满时会自动压缩。
     - 旧版（`tool_report.rs:333`）：一条 user 消息，`<conversation-checkpoint>` 外壳，写明摘要是历史、不是新的指令，没有「接着做」那句。
     - 草稿照 Claude Code 在结尾写了「接着做，不要复述或确认」。这是写进化石里的指令：检查点在下一次压缩之前每次都回放，这句会一直留着，正是 J2 要拆开的那种。`09-压缩.md` 第四节原来也这么画，那一节比 J2 早，这次一起改了。
     - 改成：检查点只说它是什么（`checkpoint-open.txt`、`checkpoint-close.txt`）；「接着做」写成 system 里核心的一行规则（`checkpoint-rule.txt`）。开头不说「上下文用尽」：手动压缩、局部压缩时这不是真的。
     - 定了：照推荐（2026-09-26 项目主人：「可以。」）。
   - 这几句会进每一次请求。以后要改，就是改这几个文件，旧会话里已经发过的照旧回放。

### 我定的

- **接口只有一个方法**：给有效历史，出请求。冻结的策略（稳定区、出厂的英文）在造组装器时交进来，一个会话一个（内核 K3：策略冻结在会话上）。
- **默认的组装放进第 2 层的新 crate**：内核只留接口，换一种组装不用改内核（`05-内核接口.md` 第五节：组装请求是独占的挂接点）。
- **检查点拼成一段字，摘要不转义**：旧版就是这样放的。摘要是模型自己写的多行正文，转义成一行读不顺。
- **检查点是人这一边最前面的一个块**：后面挨着的事实、消息和它合成一条 user 消息，它排最前（`08-上下文投影.md` 第四节第 2、4 条）。
- **人这一边的块合成一条 user 消息，事实在人的消息前面**：C2 说当前要回应的那句话离生成位置最近。回合开始时注入的事实排在触发消息前面，回合中途的排在那一步的结果后面，都照这一条。
- **状态不是 `ok` 的结果都算出错**：被拒绝、已取消、已跳过、失败，对模型都是「没成」，为什么写在内容里。
- **回合没走完的那一句当事实**：它也是人这一边的块，排在下一条人的消息前面。
- **资源文件原样用，行尾的换行也算**：少一条规矩，字节也好对。
- **单元测试用短的替身字，样本测试用真的资源文件**：渲染的规矩不随措辞变；样本会话证明真的字拼出来逐字节对。
- **总验收是样本**：样本会话本来就是照这条线编的，喂进去应该正好出那两份样本请求。

### 风险

- 摘要里要是写出了包装的结束标签，模型可能以为摘要到那里就完了。摘要是模型自己写的，出现这种字的可能很小；真碰到了，M6 做压缩时再定要不要处理。
- 「接着做」的规则在 system 里，离生成的位置远：压完那一下，她可能先确认一句摘要，或者问要不要接着做。M6 的压缩质量评测要测这一条；真这样，照 J2 的重开条件挪回检查点。
- 连着两条 assistant 消息：M1 里子代理的回报、别处来的触发还不渲染，这种回合的回复会紧跟在上一条回复后面。各家对这种排法的要求不一样，由驱动（3-4）处理；M7 渲染了回报以后就不会再有。
- 资源文件的换行在 Windows 上变成 CRLF：`.gitattributes` 已经一律 LF（0-3），样本测试会在三台机器上核对。
