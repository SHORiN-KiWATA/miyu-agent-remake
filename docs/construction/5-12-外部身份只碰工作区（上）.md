## 施工单 5-12 上：外部身份的会话只碰得到自己的工作区

状态：2026-10-11 合了（af91686a，CI run 1687；第一次 Windows 上测试的期望没照模板转义反斜杠，改了）。`11-权限与沙盒.md` 第三节「外部身份」、`18-通讯平台.md` 第九节，2026-10-11 项目主人定（改掉 09-25 的「群里不碰主机」）：群会话（和别的外部身份的私聊）有 `shell`、文件类工具，读写都只限这个会话的工作区，联网不限，越过的一律拒，不派子代理。

### 拆成上下两步

- **上（这一步）**：权限策略照会话认：场所会话、属主不是管理员的，文件类工具只放行工作区（和加进来的目录）里的，外面的连读一律拒；命令一律拒。子代理本来就只给本机的会话（`Agents::allowed`），不动。
- **下**：沙盒多一档「读也只限工作区」（Linux Landlock、macOS Seatbelt、Windows），这种会话的命令在这一档里跑，再放开命令。

### 这一步做什么

1. 协议端点造会话、载入会话时填 `owner_is_admin`（`Create`、`Load` 多一格）：属主是不是管理员。
2. 会话层（`open.rs` 的 `place`）：场所会话、属主不是管理员的，读出厂的两句造 [`Confined`]，交给权限策略。
3. 权限策略（`guard.rs`，判法放在 `guard/confined.rs`）：执行命令的访问类别一律拒；报了路径的，每一条换成真实的位置以后不在工作区、加进来的目录里的拒。
4. 两句新字 `core/permissions/outside-workspace.txt`、`no-commands.txt`，登记 26 第十节；不进策略快照（进了以前造的会话换不了快照），这种会话造、载入时读。说法三种语言。
5. 图纸 `session/guard.md`。
