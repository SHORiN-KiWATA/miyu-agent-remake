## 施工单 9-3（再补）：终端的图标项

状态：已完成（2026-10-09 写，同一天合进 main，d5edf5d1，CI run 1268；终端界面的会话转来，清单照 proto 上的一字不差）。

### 目的

终端界面第一次打开的引导里有「图标」那一步（终端蓝图 `docs/blueprint/tui.md`「第一次打开的引导」第 14 条、「图标」第 4 条）：没装 Nerd Font 的终端画普通字符。它要写进一个配置项，终端界面和设置页都照它。

### 这一步做什么

1. 出厂的 `resources/packages/tui.toml` 多一项 `[settings.icons]`：选项 `nerd`、`plain`，出厂 `nerd`，系统配置、个人设置都能写，当场生效。键是 `tui.icons`。
2. 生成的 Schema 和参考文件多 `[tui]` 一段：`docs/designs/samples/config/` 六份样本、`docs/blueprint/config.md` 里嵌的两块照生成的更新；`miyu config get` 的整份列表多一行。

### 不做什么

- 终端界面怎么读它、引导怎么写它：终端界面的会话做（`config.get`、`config.set`）。核心不认这一项的意思。

### 验收

1. 测试：生成的文件和样本逐字节比（`crates/miyu/tests/settings.rs`），`miyu config get` 列出全部（`crates/miyu/tests/config.rs`）。
2. `cargo xtask check` 八项；三台 CI 和长跑。
