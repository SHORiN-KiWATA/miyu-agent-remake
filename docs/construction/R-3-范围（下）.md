## 施工单 R-3（下）：范围

状态：已完成（2026-10-07 写、施工、验收；CI run 37593287039 三台和长跑全绿；范围两种是项目主人 2026-09-25 定的（17 L2、L3），默认值写在人格里、开会话时能换是 2026-10-07 人格与预设走查 E1；只有技术细节，照施工方案第一节第 1 条直接做）。

### 目的

每个会话开局时定下记忆的范围：跟着人格（默认）、只在这个会话里、不开。`miyu ask --no-memory` 开的会话不召回、不记，工具面上也没有三件工具。

### 蓝图改哪几节

- `memory.md`「范围」（已改）：三种、默认照 `persona.toml`、`session.create` 的 `memory`、记进快照、子代理 `off`、每个范围一处记忆（`session` 的放在会话目录里）、听众和记忆账号分开。施工步子把对外的部分拆成 R-3（补）。
- `17-记忆.md` 第七节（已改）：跟随会话的记在会话目录里，不在会话日志里，写明为什么。
- `personas.md`：`persona.toml` 多一张 `[memory]`，`scope` 两种值。
- `policy.md`：快照多 `memory`（排在最后；以前造的没有，照 `persona`）。
- `protocol.md` 的 `session.create`：多 `memory`。`cli/ask.md`：`--no-memory`。

### 定了的（技术细节）

1. **房间** `Room`（`miyu-store/src/recall/room.rs`）：`Persona { account, persona }`、`Session { account, session }`，两份登记（`RecallIndexes`、`MemoryLogs`）都照它开；路径照「范围」那一节。删会话照旧只拿掉人格那几间里的（会话那一间跟着目录走）。
2. **快照**：`Snapshot.memory` 是字符串（`persona`、`session`、`off`），没有的照 `persona`，不认识的照 `off`（宁可不记，不往不知道的地方写）。
3. **接线**：`memory::connect` 多收范围和属主：`off` 的什么都不接；`session` 的照会话那一间；听众照属主。工具面（`Agents::face`）照范围：`off` 的没有三件。
4. **子代理**：快照写 `off`，所以不用另判有没有父会话（原来照 `lineage` 判的两处换成照范围）。

### 不做什么

- `memory.*`、`miyu memory`、三种清空：R-3（补）。
- 预设开不开记忆、派子代理时指定：P-2。
- 群里的听众：O 线。

   - 人格的文件：`[memory] scope` 读得出两种，别的值、别的键报错带行号；没写是 `persona`。
   - 快照：带 `memory` 的读回一字不差；以前造的没有，照 `persona`。
   - 会话：`off` 的工具面没有三件、说过的一轮不进回合库；`session` 的记在会话目录里、别的会话搜不到；`persona` 照旧；子代理照快照是 `off`。
   - 协议：`session.create` 的 `memory` 三种和写错的；不写照人格的。
   - 命令行：`miyu ask --no-memory` 造的会话是 `off`。
2. 手写变异 12 个左右，全被逮住；`cargo xtask check` 全过；三台机器的 CI 和长跑全绿。
