## 施工单 5-9：Windows：跑

状态：暂停（2026-09-29 项目主人定：先做 5-10、5-11，以后再接着做）。仓库里还没有这一步的代码。

### 目的

Windows 上沙盒里的命令以 5-8 装好的沙盒用户的身份跑，照规格管住读写：工作区能写，数据根读写都不行，别处只能读（`11-权限与沙盒.md` 第四节、第六节 Windows）。原来的清单：受限令牌、访问控制、单独的桌面、git 的 `safe.directory`。

### 已定

- **沙盒用户能读你整个家目录**：装的时候给家目录加一条「沙盒用户可读」，数据根另外拒绝（2026-09-29 项目主人定）。和 Linux、macOS 的「读整盘放开」一致；沙盒用户是另一个账号，不加这一条，它读不到你的家目录。
- **单独的桌面拆成单独的一步**（2026-09-29 项目主人定），读写那一层先做。

### 虚拟机上的实验（2026-09-29，一次性的实验程序，没进仓库，做完已撤干净）

| 项 | 结果 |
|---|---|
| 工作区写、家目录读 | 能 |
| 家目录别处写、系统的公共目录写、沙盒用户自己的目录写 | 拒绝 |
| 数据根读 | 拒绝 |
| cmd、PowerShell、cargo 编译运行 | 能 |
| git | 仓库属于你，没登记 `safe.directory` 时 git 不认；经环境变量登记以后照常 |
| 退出码 | 原样交回 |
| 停掉外层 | 沙盒里的整棵进程树跟着停 |
| 每条命令多花的时间 | 约 80 毫秒（直接跑中位 12 毫秒，经沙盒 93 毫秒） |
| 家目录加一条可读 | 15.3 万个文件 27.5 秒；撤掉 17 秒 |

- **单独的桌面还没找到办法**：在你登录的桌面会话里，跟你共用当前桌面能跑，另开一套被系统拒绝；SSH 这类没有桌面的会话里正好反过来。
- 仓库里的样子照旧：Windows 上的助手不收紧，探测报「没有可用的手段」，沙盒用不了，工作区这一级每步问人（`11-权限与沙盒.md` 第二节）。
