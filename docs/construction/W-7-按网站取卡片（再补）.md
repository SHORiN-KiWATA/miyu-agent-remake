## 施工单 W-7（再补）：按网站取卡片

状态：已完成（2026-10-03 项目主人真网络实测通过；施工单 2026-10-02 写，项目主人要的：链接卡片支持 YouTube、B 站视频、维基百科和 ArchWiki 这类 wiki 站；网页的会话实测、提了建议；技术细节主会话定）。在 W-7 补（解压、head 后面的标签）合了以后做，改的是同一批文件。

### 目的

网页的会话照 main 实测（2026-10-02）：
- YouTube：og 就够了。
- B 站：没有卡片（真原因是页面压着发、我们没解，W-7 补修了；基本的 og 卡片 W-7 补以后就有）。项目主人要的封面、UP 主、时长要走 B 站的接口。
- 维基百科：有标题和图，描述是空的（维基百科没有 `description` 的 meta），标题带「 - Wikipedia」「 - 维基百科，自由的百科全书」。
- ArchWiki：只有标题，没有描述、没有图。
- 有的站被人机验证页拦住，卡片标题成了「安全检查」：出了一张假卡片。

要做的（主会话定）：
- **按站取的一层**：`miyu-net` 里多一层「站」：先照地址认是不是认得的站，认得的照它的办法取；不认得的照现在的 og 办法。站的办法都只经现在的抓取（同一个地址闸、同一套代理、同样的时限和上限），不另开客户端。
  - **B 站**：认 `bilibili.com/video/BV…`、`/video/av…`、`b23.tv/…`（短链照现在的规矩跟到跳转后的地址再认）。认出来的整页读完，照页面脚本里 `window.__INITIAL_STATE__` 的 `videoData` 取标题、简介、封面（照图的规矩存成 blob）、UP 主（`owner.name`）、时长（`duration`，秒）；没有这份数据的照页面的 og 和 `<meta name="author">`。页面标题是「视频去哪了呢？」这类的（表放 `link_preview.json`）：不出卡片，`no_preview`。页面 og 的简介里还带着 `{$0}` 这种没填的模板的，那一格当没有。
    - 原来定的是先调接口 `api.bilibili.com/x/web-interface/view`；2026-10-03 项目主人实测，没登录的请求它回 HTTP 412，带上 `buvid3` 也一样，页面照常给，脚本里那份数据和接口的字段一样，所以改成读页面（主会话定，`net.md`「起草时定的」第 14 条）。
  - **MediaWiki 站**：认法是页面 `<head>` 里 `<meta name="generator" content="MediaWiki …">`，或者 `link_preview.json` 里列的主机（维基百科各语言、`wiki.archlinux.org` 这类）。
    - 都走 `api.php?action=query&prop=extracts|pageimages&exintro&explaintext&titles=<标题>&format=json&redirects=1`，站名放在同一个请求里（`meta=siteinfo`）；维基百科也走它，不走 REST 的 `page/summary`（施工时定：一条路认所有 MediaWiki 站，REST 又不给站名，`net.md`「起草时定的」第 12 条）。
    - 没有 TextExtracts 扩展的（回应里没有 `extract`），第一段照 `action=parse&section=0` 回的正文找第一段非空的 `<p>`（去标签、收拢空白）：不回头再读页面（施工时定，第 13 条）。
    - 标题照 API 的；页面标题里「 - 站名」那段尾巴去掉，站名放进 `site`（照 `og:site_name`，没有用 API 的站名）。
  - **YouTube**：认 `youtube.com`、`www.youtube.com`、`m.youtube.com`、`youtu.be`。YouTube 的 `<head>` 里有 `<title>`，`og:*` 和 `itemprop` 那几个 `<meta>` 却在 `</head>` 后面（频道页 `og:title` 在第 77 万字节左右）：W-7 补的规矩「有 `<title>` 就停」在它身上读不到 og。YouTube 这一站不照那条停：读到找到 `og:title` 为止（视频页再加上 `itemprop="duration"`），最多 `max_bytes`。普通网页照旧，不为它们多下载（2026-10-02 主会话实测 W-7 补以后：频道页只有标题，没有简介和图）。
    - 时长从 `<meta itemprop="duration" content="PT…">` 读（ISO 8601 的时长换成秒），读不到不写。频道名照 `<link itemprop="name">` 或者 og 里有的，读不到不写。
- **人机验证、挡爬虫的页面**：认出来就不做卡片：`card` 是 `null`、`why` 是 `no_preview`，记一次 `no_preview`。认法放在 `link_preview.json` 里一张表（标题完全对上的几种：`Just a moment...`、`Attention Required! | Cloudflare`、`安全检查`、`Access denied` 这类；响应头 `cf-mitigated: challenge`；403、503 回的 HTML），以后加不用改代码。
- **卡片多三格**，没有的不写：`kind`（`"video"`、`"article"`、`"page"`：B 站、YouTube 是视频，MediaWiki 是文章，别的是页面）、`duration`（视频的秒数，整数）、`author`（UP 主、频道名）。
- 站的规矩（认哪些主机、接口地址的样子、人机验证的表）放在 `link_preview.json`，代码里只有「怎么取」。

### 蓝图改哪几节

- `docs/blueprint/net.md`：加一条「按站取」（三种站、认法、取法、退回）、人机验证那一款；`link.preview` 回应的三格；「守着它的」；「施工时定的」。
- `protocol.md` 里 `link.preview` 那一段指过去的形状。
- 先例：W-7、W-7 补的 `miyu-net`（抓取、地址闸、元数据、图存 blob、测试的口子 `LinkPreview::testing`）。

### 不做什么

- 别的站（推特、知乎……）：以后照同一层加。
- 登录才看得到的内容：不做。

### 验收

1. 测试（先写，退回改之前的代码要红）：全在本机假服务器上（假的 B 站页面、假的 MediaWiki API），照 W-7 测试的口子把它们当公网：
   - B 站：BV、av、短链跟跳转都认；页面脚本里的数据做成的卡片带封面、UP 主、时长、`kind: video`；没有数据的退回 og；「视频没了」的页面不出卡片；
   - MediaWiki：`api.php` 的 `extract`、缩略图、站名；没有 TextExtracts 退回第一段 `<p>`；标题去尾巴、站名进 `site`、`kind: article`；
   - YouTube：时长从 ISO 8601 换成秒；读不到不写；
   - 人机验证：表里的标题、`cf-mitigated`、403/503 的 HTML 都回 `no_preview`，不出卡片；
   - 不认得的站照旧 og、`kind: page`；
   - 所有站的请求都过地址闸（站的接口指到内网的被拒）。
2. 给模型看的字：没有。请求形状探针零变化。
3. 真网络（主会话合并前做）：一个 B 站视频、一个 YouTube 视频、一个维基百科条目（中、英各一）、一个 ArchWiki 页面都出像样的卡片；一个被人机验证拦住的站不出卡片。
4. 手写变异 15 个左右，挑关键的，全被逮住；`CARGO_BUILD_JOBS=5 cargo xtask check` 八项全过；三台机器的 CI 和长跑全绿。
5. 协议回应多了格：合了主会话告诉两个头，附 sha 和形状。

### 施工时定的（2026-10-02、10-03 主会话定）

- MediaWiki 站都走 `api.php`，维基百科也是，不走 REST（`net.md`「起草时定的」第 12 条）；没装 TextExtracts 的照 `action=parse&section=0` 找第一段（第 13 条）。实测 ArchWiki 就没装，第一段只认正文最外层的 `<p>`：它顶上的「Related articles」框里也有 `<p>`。
- B 站不调接口，读页面脚本里的 `__INITIAL_STATE__.videoData`（第 14 条）：实测接口对没登录的请求回 HTTP 412，带上 `buvid3` 也一样；页面照常给，整页一二百 KB，读完。删了的视频页面标题是「视频去哪了呢？_哔哩哔哩_bilibili」，放进 `gone_titles`。
- YouTube 读到了时长的才算视频（第 15 条）：频道页、列表页是 `page`。
- 真网络的实测是 `tests/live.rs`，标了 `#[ignore]`，还要设 `MIYU_NET_LIVE=1` 才连外网（第 17 条）：CI 的长跑用 `--ignored` 跑所有标了的测试，第一版没有这道锁，长跑在 GitHub 的机器上真去连了外网、B 站连不上就红了。
