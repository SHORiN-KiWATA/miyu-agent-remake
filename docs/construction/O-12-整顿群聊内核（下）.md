## 施工单 O-12（下）：整顿群聊内核：结果和小处

状态：已完成（2026-10-07；只有技术细节，照施工方案第一节第 1 条直接做；分身施工，主会话审）。

### 目的

O 线自查（2026-10-07）剩下的几处，接着 O-12（上）收拾：「冲她来」和 base64 解出来的字由群聊内核交出来，桥不用自己再写一遍；放得进非法值的类型改成只能经读或构造函数造；只有测试在用的名字删掉；撞车的名字改掉；图纸和代码对上。行为只多两样新的（`addressed`、`Base64::reveal`），别的不变，测试照旧守着。

### 蓝图改哪几节

`docs/blueprint/chat.md`：

- 「在哪」：加 `rules/ids.rs` 管 `Venue`、`VenueKind`；`inbound/addressed.rs`；`chatty/supersede.rs`（顶替）和 `chatty/dispatch.rs`（分派）分开写。
- 第一条：
  1. `Venue` 的几格改成私有，由 `Venue::new(platform, kind, number) -> Result<Venue, FormatError>` 造，规矩照原来 `id()` 查的那一份；`id()` 改成 `-> &VenueId`，不会失败；读的方法 `platform()`、`kind()`、`number()`。原来的格 `id`（平台里的编号）改叫 `number`，免得和 `id()` 撞。`Venue::parse` 照旧。`Venue`、`VenueKind` 挪进 `rules/ids.rs`。施工时定的第 14 条改成「构造函数到位」。
  2. `Read` 改名 `Parsed`：门面里和判官的 `read` 撞。
  3. Rust 那张表补上 `Entry { value, origin }`。
- 第二条：
  1. `Rate`、`Sleep` 的格改成私有，只能由 `Rate::read`、`Sleep::read` 造：读出来的不会是 0 个回合、窗口不会是 0、开始不会等于结束（自查第 14 条：开始等于结束时回合闸会推迟到已经过去的时刻，桥空转一分钟）。
  2. 新：`addressed(kind, mentions_me, quotes_me, text, keywords) -> bool`，算 `Said::addressed`：私聊一律是；@ 了她、引用的是她的消息是；正文去掉开头的空白以后以某个触发词开头是（场所规则的 `keywords`；空的不算；区分大小写；名字也算触发词，写在 `keywords` 里，出厂是空的）。照旧版：唤醒词只认开头，不认中间（旧版 `group_trigger_text`），私聊不看唤醒词。
  3. 新：`Base64::reveal(text) -> Option<String>` 公开：正文里每一段够 `min_chars` 的 base64，照原来的办法解、筛，去掉重复的，照出现的先后用换行接起来；一段都没有是 `None`。违规关键词那条规则改用它，结果不变。桥拿它填判官的 `Ask.decoded`：照旧版，解得出来就给判官看，不只是命中关键词的时候（旧版 `decode_base64_text`）。解出来的字节读不成 UTF-8 的整段不要，不再换成替换字符：长数字串、哈希这类会解出乱码，白花判官的 token；照旧版 `decode_base64_text`（施工时定的第 20 条，施工中加）。
  4. `InboundRule::name()` 删掉；`Said.sender` 的说明去掉「留给往链里加的规则」。
  5. 施工时定的：补这一步的几条（下面「要定的」）。
- 第三条：`Bonus::name()`、`Lift::name()` 删掉。
- 第四条：`Pending.hits`、`Supersede::Inherit.hits`、`Supersede::Rejudge.hits` 改叫 `conditions`（原来读着是 `pending.hits.hits`）；顶替和分派拆成两个文件，测试跟着拆。
- 第五条：`OutboundRule::name()` 删掉。
- 第六条：`Message`、`Role` 改名 `JudgeMessage`、`JudgeRole`（和内核的 `request::Message`、两个 `Role` 撞）；`Ask.decoded` 的说明改成「`Base64::reveal` 解的」；「怎么走」第 3 条的 `model` 改成照出厂参数 `[judge]`（第七条第 5 条），场所规则按场所改随 O-15（原来写「照场所规则」，规则属性表里没有这一项）。

`docs/designs/18-通讯平台.md` 第七节那张加值项表的「冲她来」一格：补一句「名字写在触发词里」。
