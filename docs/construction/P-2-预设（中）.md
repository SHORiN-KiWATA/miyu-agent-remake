## 施工单 P-2（中）：照预设挑工具面

状态：已完成（2026-10-08 写、施工完；CI run 1143 三台和长跑全绿；方向是施工方案第三节 P-2 那一行和人格与预设走查 C1、C4、E2（项目主人 2026-10-07 定照推荐），Y7、Y8；技术细节主会话定）。

### 目的

预设真的管用：开发预设开出来的会话没有记忆的三件工具、不召回、没有角色扮演提示；在预设里关掉 `shell` 的，工具面上就没有它。装了、但这个预设没开的软件，她知道有、知道该换哪个预设（Y8）。

### 蓝图改哪几节

- `presets.md`：「怎么走」多「照预设挑」；`preset.get` 多 `missing`；「还没有的」去掉这几条。
- `agents.md` 或 `tools/README.md`（工具面怎么挑的那一节）：多预设这一道筛。
- `policy.md`、`kernel/request.md`：system 多「装了没开」那一行（26 第四节第 5 块）。
- `memory.md`「范围」：预设没开记忆的会话一律 `off`。
- `personas.md`：预设没开角色扮演的，没有角色扮演提示和风格锁。
- `26-提示词.md` 第十节登记簿：多一行。

### 定了的（技术细节，主会话定）

1. **工具归哪个包**：工具目录登记时按包登记（`Catalog::in_packages`），记下每件工具的包；基础系统 `basesystem`、记忆 `memory`。只交一串工具的老写法（测试里多）照旧，全算 `basesystem`。
2. **自带的软件**：`basesystem`（基础系统的工具）、`memory`（记忆的三件工具和回合开始的召回）、`roleplay`（人格的角色扮演提示和风格锁）。联网 `net`、长期目标 `goal` 这些等它们的工具做出来再登记。清单装的包里 `process` 那种（桥）也算软件（它的平台工具以后随它）；`ui` 那种是头，不算。
3. **开不开**：一个软件开着 = `[software]` 里写了照写的，没写的照 `unlisted`。工具面 = 开着的软件的工具，减去 `[tools]` 关掉的，再照原来的几道筛（场所、子会话、能不能确认……）。
4. **记忆**：`memory` 没开的会话，记忆的范围一律 `off`（同子会话），不管 `session.create` 的 `memory` 写了什么：开不开记忆归预设（E2），范围归开会话时（L3）。
5. **角色扮演**：`roleplay` 没开的会话，快照里没有角色扮演提示，system 最后也就没有风格锁。
6. **装了没开的那一行**（Y8、C4）：开着的软件以外、装了的那几个，照编号排，一行英文短句写进 system，排在核心的几行后面、风格锁前面（26 第四节第 5 块）。没有没开的不写这一行，以前造的快照、功能全开的会话 system 一个字节不变。字放 `core/` 里一份，登记、量 token。
7. **快照**：多 `preset`（编号），以前造的没有。这一步改了预设的文件，开着的会话照旧，新开的照新的；改了下一个回合换上（K3）随 P-2（下）一起做：要和人格那份指纹一起换，工具面也跟着变，`swappable` 要重新想。
8. **`preset.get`** 多 `missing`：`[software]` 里写了、这台机器上没装的（例如出厂开发预设的 `net`、`goal`），照编号排；界面照它写「没安装」（16 第五节）。

### 不做什么

- 改了预设文件开着的会话下一个回合换上：P-2（下）。
- 预设里写配置值（D1）、子代理选人格和预设（C5）：P-2（下）。
- 单件打开某个包里的一件：C1 说先不做。
- 联网、长期目标这些软件本身：各自的步。

### 验收

1. 测试先写，改之前红：开发预设开出来的会话工具面只有基础系统、没有记忆三件、不召回、范围是 `off`；关掉 `shell` 的没有它；功能全开的和以前一样；角色扮演没开的没有提示和风格锁；装了没开的那一行照编号、只在有没开的时候写；子会话、场所会话照预设筛；`preset.get` 的 `missing`。
2. `request_shape_probe` 照旧（功能全开的会话一个字节不变）；新的那一行量 token、登记；手写变异 15 个左右；`cargo xtask check` 八项；三台 CI 和长跑。
3. 合进 main 以后告诉两个头（`preset.get` 多 `missing`）。

### 施工结果（2026-10-08 主会话）

1. `miyu-tool`：工具目录按包登记（`Catalog::in_packages`），记下每件工具的包，`package_of`（以前的名字照现在的那一件）、`packages`；只交一串工具的 `Catalog::new` 全算 `basesystem`（`BASESYSTEM`）。`miyu-memory` 的包编号 `PACKAGE` 公开出来，核心起来时照两个包登记。
2. `miyu-policy`：`PresetFile::opens`、`keeps`；`Chosen`（开会话时找好的预设：编号、文件、装了没开的）；软件编号 `MEMORY`、`ROLEPLAY`；快照多 `preset`（`PresetPin`：编号和没开的）；`Snapshot::with_preset` 记预设、去掉角色扮演提示、写那一行。`CoreLines` 多 `preset_off`。快照的两种错挪成 `snapshot/error.rs`（行数门禁：`snapshot.rs` 加了这一格到 514 行）。
3. `miyu-session`：`Create.preset` 换成找好的 `Chosen`；工具面多预设那一道筛；`memory` 没开的范围一律 `off`；拼快照、换人格重拼都带上快照里的预设。
4. `miyu-endpoint`：`installed`（工具目录里的包、`roleplay`、清单装的 `process` 包）、`chosen`；造会话、派子代理都交 `Chosen`（子会话照父会话的编号重新找，找不到的不派）；`preset.get` 多 `missing`。
5. 定了的第 2 条改了一处：`roleplay` 算装了、开发预设不开，但不进装了没开的那一行（它没有工具，列出来反倒像是不许演）。
6. 给模型看的字一份：`core/preset-off.txt`，`Installed but off in this session's preset: {packages}.`，只陈述是什么。开发端点上量：放在 system 里写 `memory` 一个是 12 个 token，每多一个包约多 2；登记在 26 第十节，`docs/blueprint/prompts.md` 照它重新生成。功能全开的会话一个字节不变：探针的样本测试照旧过。
7. 手写变异 17 个：第一轮漏了一个（工具面不看包、全当基础系统）：现有的用例里记忆的三件本来就会被「范围是 off」那一道筛掉，补了一个关掉基础系统、记忆照开的预设以后逮住，17/17。
8. 真模型实测（2026-10-08，开发端点的 `deepseek-v4.1-flash`，沙箱数据根）：`preset.default` 设成 `dev`，让她「记住我的猫叫小白」，她说这个会话里记忆是关的（预设中 memory 为 off）、建议写进文件或在预设里打开记忆；改回 `full` 再说一次，她直接调 `remember` 记下。两个会话的 `session.created` 分别记着 `dev`、`full`。
