## 施工单 D-4 补：被沙盒挡下直接带参数重跑

状态：已完成（2026-10-07 写、施工完；CI run 1060 三台和长跑全绿；项目主人同一天定，经网页的会话转来；写法、实测、技术细节主会话定）。

### 目的

工作区这一级，她的命令被沙盒挡下、任务又要写到外面时，直接带 `outside_sandbox` 重跑，由确认窗口去问人，不先在聊天里多问一轮。网页实测（会话 `…fc6c4777`，项目主人说「试试在工作区外运行命令」）里她先问了一句「要我现在申请一次沙箱外执行吗」，项目主人没看到确认窗口，以为是头漏了弹窗。

### 蓝图改哪几节

- `tools/shell.md`：参数表 `outside_sandbox` 那一行、说明的样子。
- `prompts.md`（`cargo xtask prompts` 重新生成）。
- 登记簿 `26-提示词.md` 第十节 `shell.json` 那一行、量 token 的记录。
- `sandbox/linux.md`：新一节「已知的限制」。

### 定了的（技术细节，主会话定）

1. **照 Claude Code**：它的沙盒那一段写「看到沙盒挡下的迹象，立刻带 `dangerouslyDisableSandbox: true` 重试（别问，直接做）……这会请人批准」。参数说明改成两句：`Rerun a command the sandbox blocked. When the sandbox blocks a command, retry with this right away instead of asking first, because setting it is what asks the user.`
2. **不设「任务需要」的前提**：第一版写了「被挡下、需要时重跑，别先在聊天里问」，项目主人那句原话下她仍把「试试」当成摸边界、照样先问（6/9）；去掉前提以后 4/5。
3. **写在工具说明里，不写进工具结果**：执行器只知道命令在沙盒里跑、退出码不是 0，说不准是不是沙盒挡的；Claude Code 也写在说明里。
4. **已知的限制**：实测时撞见 `touch` 工作区外已有的文件「成功」，查明是 Landlock 不管改时间戳，内容和新建照样挡下（经助手直接跑 300 次新建全挡下），写进 `sandbox/linux.md`，不修。
