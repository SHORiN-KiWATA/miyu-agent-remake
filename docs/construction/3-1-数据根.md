## 施工单 3-1：数据根

状态：已完成（2026-09-26：三台机器的 CI 全绿、长跑也绿、测试全过，照施工方案第一节第 1 条算验收通过）。

### 目的

Miyu 在每台机器上找到自己的数据根：默认位置照平台来，`MIYU_HOME` 能指到别处；第一次用时建好骨架，只有本人能进。缓存目录一起找出来。

这是 M3 的第一步，也是第一个真碰磁盘的 crate：`miyu-store`，第 3 层（执行器）。3-2 的会话日志、3-3 的 blob 也放这里。

### 图纸

- `07-存储.md` 第二节「目录布局」「默认位置」已经画了；这一步补的：
  - 怎么找：`MIYU_HOME` 要写绝对路径；XDG 变量是相对路径的不算；家目录找不到就报错；别的类 Unix 照 Linux。
  - 第一次用时只建四个顶层目录；Unix 上新建的 0700，已经有的不改，由 `miyu doctor` 报告。
- `01-架构.md` 第九节：第 3 层登记 `miyu-store`。这一格和新 crate 放在同一个施工提交里：表里有、仓库里没有的 crate，门禁当场拦下。

### 不做什么

- 核对目录的属主：套接字的目录要查（`04-核心协议.md` 第二节），随 3-8 做；数据根在本人的家目录下，别人建不了。
- 账号的家目录 `home/<账号>/`：账号从哪来、叫什么，随首次运行定；3-2 起账号当参数传进来。
- 密钥文件的权限：随写密钥的那一步。
- 资源目录（出厂的人格、提示词）：3-6。套接字放哪：3-8。

### 我定的

- **新 crate `miyu-store`，第 3 层**：存储的执行器。
- **不引依赖**：路径、目录、权限都用标准库；测试用的临时目录自己建（进程号加序号），不引 `tempfile`。
- **找数据根照一份环境快照算**：测试喂一份快照就行，不改进程的环境变量（改了会串到同时跑的别的测试）。平台也是快照的一格，三个平台的默认位置在任何一台机器上都测得到；运行时照编译的目标平台填。
- **`MIYU_HOME` 相对的拒绝，空的当没设**；XDG 的两个变量相对的当没设。
- **找不到家目录报错，不猜**。
- **已有的目录权限不改**：权限不对由 `miyu doctor` 报告（`22-命令行.md` 第五节）。
- **缓存目录只找，不建**：用到它的（例如语音的模型文件）到时候建。

### 验收

1. `step/3-1-root` 分支的 CI：三台机器全绿，长跑也绿。
2. `cargo test`：
   - 三个平台的默认位置，数据根和缓存各一格；XDG 变量设了的照它；`MIYU_HOME` 盖过默认，缓存不跟着变。
   - `MIYU_HOME` 相对的拒绝、空的当没设；XDG 相对的当没设；家目录、`LOCALAPPDATA` 找不到报错。
   - 建骨架：在临时目录里建，四个顶层目录都在，建两次不出错；Unix 上新建的权限 0700；已经有的目录权限不改。
   - 读进程环境的那一个函数，在三台机器上都跑一遍，找得到家目录（CI 上）。
3. 故意改坏几处，测试变红：相对的 `MIYU_HOME` 也收、空的 `MIYU_HOME` 当设了、相对的 XDG 也算、不看 XDG、macOS 的位置写错、Windows 的缓存写错、缓存跟着 `MIYU_HOME`、不设 0700、骨架少一个、相对的家目录也收、已有的也改成 0700。一共 11 处。
   - 新加 9 个测试；`lib.rs` 的文档里 `env` 既是模块又是标准库的宏，链接要写 `mod@env`（文档门禁查出来的）。
4. `cargo xtask check` 七项全过。

### 风险

- **测试碰到真实的数据根**：测试一律喂快照、在临时目录里建；读进程环境的那一个测试只找、不建。
- **Windows 上的路径和权限**：权限只在 Unix 上设和查；Windows 的默认位置靠 `LOCALAPPDATA`，CI 的 Windows 机器上有它。
