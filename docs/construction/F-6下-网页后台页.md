### 目的

核心已经能读后台页的文件（`package.file`，F-6 中）。正式的网页软件 `miyu-web` 要把它给页面：页面带登录令牌换一张票据，框照票据拿文件，文件放在隔离的框里显示。`miyu web --package <编号>` 打开时直接到这个软件的后台页。网页演示的桥（proto/web-demo）已经照同一套做通、实测过，这一步把它搬进 `miyu-web`。

### 这一步做什么

1. `POST /page`：带登录令牌，正文 `{"package"}`；照 `package.list` 查有没有后台页；造票据（同 `/media` 的写法、上限、过期，各是各的一份），回 `{"url":"/p/<票据>/<包>/"}`。
2. `GET /p/<票据>/<包>/<路径>`：票据和包对得上才给；照 `package.file` 一块块读、一块块写；类型照 `web.json`；响应头沙箱、不许联网、只许嵌在网页里、允许空来源取（`web.json` 的 `backstage_csp`）。
3. `miyu web --package <编号>`：主程序照原样交给 `miyu-web open`，网址 `#` 后面多一个 `package=<编号>`。
4. 票据 `Tickets` 做成泛型，两边各一份；`miyu-webserve` 的 `decode` 开放出来。
