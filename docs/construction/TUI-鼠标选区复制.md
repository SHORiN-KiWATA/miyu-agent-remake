# TUI 鼠标选区复制

状态：已完成，项目主人验收通过（2026-10-03）。

## 目的

鼠标选字后直接复制；粘贴占位符复制原文，文件块复制路径。

## 蓝图改哪几节

`tui.md`「鼠标」「正文」「输入框」「后台命令、子代理和侧边栏」：松开复制、双击选词复制、保留选区；正文增加块范围与原文的复制映射。碰到部分收起的标签也展开整块，跨折行不重复，展开后按实际选区复制。

## 不做什么

不改变核心协议、终端剪贴板通道、点击展开和附件打开方式。

## 验收

- 复现已确认：旧实现的鼠标松开测试、正文粘贴块与文件块展开测试均失败，修复后通过。
- Linux：`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings`、`cargo test --quiet`、`git diff --check` 通过；628 项通过、10 项原有量尺忽略。
- 新伪终端测试：真界面连测试核心，输入框拖出到右侧再松开、正文只选部分标签，均发出一次原文的 OSC 52，不把标签复制进去、不点开正文。
- 原文末尾空格和换行保留；同名块、跨行、反向、附件标签、多个条目均有回归测试。
- demo 不属于工作区门禁，未改核心；本次没有进行 macOS、Windows 实测。
- 改动在从 `proto/tui-demo` 开出的独立分支 `step/tui-mouse-copy`，项目主人验收通过后整合进演示分支。
真人拖选正文和输入框，松开后粘到别处：得到原文；同名块、跨行、反向和部分标签不串不重复；侧栏选字同样复制；单击链接、附件、普通空白不误复制。

## 风险

折行的同一块重复展开：用条目与块的编号去重。普通文本长得像标签：只依范围元数据处理。缓存每行重复原文：原文共享。复制失败沿用已有提示。
