## 施工单 O-6：核心：斜杠命令由核心解析（头一批）

状态：已完成（2026-10-07 写、施工完；CI run 1034 三台和长跑全绿；项目主人同一天定：单开一步排在 O-3 后面，清空的命令叫 `/clear`、别名 `/reset`，`/stop` 是全停——打断这一轮、停掉后台命令和子代理，排着的话留在历史里不回，终端、网页、群里都一样；形状给通讯平台的会话对过；技术细节主会话定）。

### 目的

人在 QQ 私聊、群里、终端、网页打 `/clear`、`/stop`，头把原文交给核心，核心认命令、判谁能用、执行，回执那一句照语言写好交回去。头不用自己认命令；以后的命令目录（`command.catalog`，M9）在这上面长。

### 蓝图改哪几节

- `protocol.md`：方法表多 `command.run`，单开一节；`session.interrupt` 的 `queued` 多 `keep`；原因码 `unknown_command`、`command_not_allowed`，两句给人看的话；`bad_params` 多两种。
- `kernel/session.md`：命令表 `Interrupt` 多 `Queued::Keep`、新命令 `Ran`；「排队的消息」第 3 条；新一节「斜杠命令」。
- `kernel/events.md`、`kernel/events-bodies.md`：新种类 `command.ran`。
- `kernel/request.md`：`command.ran` 不渲染、不改接着写的记号。
- `venues.md`：「斜杠命令」一段，状态行。
- `18-通讯平台.md` 第十二节：命令名、`/stop` 全停。

### 定了的（技术细节，主会话定）

1. 单开方法 `command.run {session, text, as?}`，不混在 `session.send` 里：头不用认命令，`session.send` 的原文永远是一句话。回应 `{"command", "events", "said"}`。
2. 认法：开头的空白不算，`/` 开头（不是的参数不对），名字紧跟着 `/`、到空白为止，后面跟的字不理；大小写照原样（`/Stop` 认不出）。
3. 谁能用：本人（本机的头、私聊里对应表认出的本人）、群里对应表里有的外部身份（带 `account`）、`role` 是 `manager` 的。别人 `command_not_allowed`。
4. `/stop` 用新的 `Queued::Keep`：队清空、不撤回、不接着开，排着的照样在日志里，下一句话开的那一轮看得到。没有回合在进行的照样停后台的、照样记。后台的走执行器原有的「全停」（`Halt::All`）。
5. 记下命令另起一种事件 `command.ran`（原文、正名），派生编号 `<编号>/ran`：命令本身照它自己的编号执行、照编号只生效一次，记的这一条也一样。被拒的什么都不记。不进她的上下文。
6. 回执那一句放在 `core/human/<语言>.json` 的 `said`（`commands/cleared`、`commands/stopped`），照连接的语言；读不出来的回空字、记一行运行日志（命令已经执行了，不为一句回执报错）。

### 不做什么

- 命令目录 `command.catalog`、扩展登记的命令、`/models` 这类：M9。
- 属主是系统账号的会话（别人的私聊、群）：O-4；判谁能用的规矩这一步已经写好。
- 命令的输出走出站链、长文转图：桥那一头。

### 验收

1. 测试先写，改之前红：内核留着的打断、记下命令；组装不渲染、不改接着写的记号；协议上 `/clear`、`/reset`、`/stop`（排着的留着、子代理停了、没有回合也记）、认不出的、参数不对的、内核拒的、同一个编号只算一次（重启以后照样）、场所里谁能用；`session.interrupt` 收 `keep`；随机测试多两种输入、一条路。
2. 手写变异 20 个左右，全被逮住；`cargo xtask check` 八项；三台机器的 CI 和长跑。
3. 合进 main 以后告诉通讯平台的会话和两个头。

### 风险

- 群里的普通人用 `/stop` 打断别人：判谁能用由核心做，桥报的 `role` 只能降权，主人照对应表认。
- 记下的那一条混进她的上下文：渲染和接着写的记号都跳过它，测试守着。

### 施工结果（2026-10-07 主会话）
