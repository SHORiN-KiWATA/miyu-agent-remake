## 施工单 3-8：Windows 命名管道（补）

状态：施工中。

### 目的

Windows 上核心也有本机入口：命名管道 `\\.\pipe\miyu-<指纹>`，只对本人开放。核心起来的先后和 Linux、macOS 一样：拿锁，换本机令牌，建管道，位置记进 `run/socket`。头照 `run/socket` 连上，先核对管道另一头的进程是自己的，再读令牌、握手。

### 拍板的

- 项目主人 2026-09-27 定：单开一个小 crate 放开 `unsafe`，调 Windows 的安全接口。

### 图纸

- `04-核心协议.md` 第二节「各平台的坑」：命名管道默认的安全描述符允许 Everyone 读，必须显式只允许当前用户；创建时声明「第一个实例」，防止别的进程抢先占用管道名。
- `07-存储.md` 第二节：管道名 `\\.\pipe\miyu-<指纹>`；实际位置写进 `run/socket`。
- `0-1-仓库骨架.md`「我定的」：要用 `unsafe` 的 crate，只在它自己那里放开。

### 做什么

| 文件 | 装什么 |
|---|---|
| `crates/miyu-pipe/`（新，第 3 层） | 放开 `unsafe` 的小 crate，只装非调 Windows 接口不可的三样：建管道的一个实例（安全描述符只允许当前用户，可以声明第一个实例）；当前用户是谁；管道另一头的进程是谁。别的平台上是空的 |
| `crates/miyu-ipc/` | `windows.rs` 换掉 `other.rs` 的桩：监听（等连接，接走一个就建下一个实例）、连（管道忙就歇一下再连，连上核对另一头）；`place.rs` 的 Windows 那一支给出管道名 |
| `crates/miyu-endpoint/tests/socket.rs` | 端到端的测试 Windows 上也跑 |
| `docs/designs/04-核心协议.md` 第二节、`07-存储.md` 第二节 | 头核对管道另一头 |
| `docs/designs/01-架构.md` 第九节 | 第 3 层多一个 `miyu-pipe` |
| 施工图 | 3-8（补）那一张 |

### 不做什么

- 头拉起核心的握手、空闲退出：3-9。
- WebSocket：以后。

### 我定的

- **`miyu-pipe` 只装非用 `unsafe` 不可的**：建实例（tokio 带安全属性建管道的那个函数本身是 `unsafe` 的）、取当前用户的 SID、取管道另一头进程的用户 SID。等连接、管道忙了再连这些用不着 `unsafe` 的，留在 `miyu-ipc`。
- **安全描述符**：SDDL 写成 `D:P(A;;GA;;;<当前用户的 SID>)`：受保护、不继承上一层的，只有一条，允许当前用户全部权限。每个实例都带上它。
- **第一个实例**：核心建第一个实例时声明「第一个实例」。名字已经被占了（拒绝访问），就报「有别的东西」，不动它，和 Unix 上连得上的旧套接字一样。锁在手里，同一个数据根不会有别的核心，占着这个名字的只能是别的程序。
- **头核对另一头**：对照 Unix 上「连之前核对目录的属主」。连上以后问出管道服务端的进程编号，打开这个进程、取它的用户 SID，跟自己的比；不是自己的，不交令牌，报「不是自己的」。管道只对本人开放，这一步防的是核心没在跑的时候别的用户先占了这个名字冒充核心。tokio 连管道时默认只允许服务端认出头是谁、不许冒用头的身份，不用另外设。
- **管道忙**：头连的时候管道忙（核心刚接走一个连接，下一个实例还没建好），歇 50 毫秒再连，最多等 5 秒。
- **接连接改成 `&mut self`**：Windows 上接走一个连接，要把等着的那个实例换成新建的；Unix 上照旧。
- **走的时候**：Windows 上没有套接字文件要删，管道的句柄都关了它就没了。
- **不再有「还不支持」**：Linux、macOS、Windows 都能监听、连，两个 `Unsupported` 删掉。
- **lint**：Cargo 不许 `workspace = true` 以后再单改一条，`miyu-pipe` 照抄工作区的 lint，只把 `unsafe_code` 放开，另加 clippy 的 `undocumented_unsafe_blocks`：每个 `unsafe` 块都要写清为什么安全。

### 验收

1. `step/3-8d-pipe` 分支的 CI：三台机器全绿，长跑也绿。
2. `cargo test`（Windows 上的只在 CI 上真跑）：
   - `miyu-pipe`（Windows）：读回管道的访问控制列表：受保护、只有一条、给的是当前用户；同一个名字的第一个实例建不了第二个；头看得出另一头是自己；当前用户的 SID 以 `S-1-` 开头。SDDL 的写法（各平台）。
   - `miyu-ipc`（Windows）：起来、头连上、两头各说一句；一个数据根一个核心，第一个走了第二个起得来；名字被别的程序占了，起不来、不动它；没起过、走了，都是「核心没在跑」。位置（各平台，照快照）：Windows 那一支给出 `\\.\pipe\miyu-<指纹>`。
   - 端到端（协议端点，三个平台）：在真的套接字、管道上起核心，头连上、握手、造会话、说一句。
3. 故意改坏几处，测试变红：Windows 上的代码本机跑不了测试，挑几处推到 CI 上跑（施工完照实补上清单和处数）。
4. `cargo xtask check` 七项全过；推之前本机用 `cargo clippy --workspace --exclude miyu-http --exclude miyu-session --exclude miyu-endpoint --target` 查 Windows、macOS。

### 风险

- **本机测不了 Windows**：本机只能交叉 clippy 查编译，行为全靠 CI；CI 红了看日志改。
- **读回来的权限写法**：建管道时系统可能把 `GA`（全部权限）换成管道自己的写法（`FA`），测试两种都认，只查条数、给谁、受不受保护。
- **另一头的进程打不开**（别人的、受保护的进程）：当作不是自己的，报错，不连。
