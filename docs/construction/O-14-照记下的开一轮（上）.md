## 施工单 O-14（上）：照记下的几条开一轮

状态：已完成（2026-10-09 合进 main，`77b4efb4`，CI run 1314；2026-10-09 写；照 `docs/blueprint/chat.md` 第七条第 3 条第 1 项（2026-10-07 定稿，项目主人过目），形状 2026-10-09 和通讯平台的会话对过；O-14 由主会话拆成上、下，技术细节主会话定）。

### 目的

桥判过群里哪几条该她回，要叫核心「照这几条开一轮」。那几条早就旁听记下了（O-13 上），不能再发一遍：`session.respond` 拿记下的序号当触发开一轮，桥带来的几块事实排在触发前面。这一步做会话闲着的时候；正在跑一轮时并进去是 O-14（下）。

### 这一步做什么

1. **协议** `session.respond {session, to, facts}`，回应 `{"events": [...]}`（记下的 `turn.started` 和事实的序号，同 `session.send`）：
   - `to`：序号的列表，1 到 64 条，核心照序号排好、去重（重复的不拒）。
   - `facts`：可以不写，几块事实 `{kind, text}`，`kind` 照事实的类别的写法，`text` 最多 4 KiB，原样记成 `context.injected`，`by` 是调用的连接（桥是模块 `onebot`）。
   - 写错的（`to` 空的、超过 64 条，事实的格不对、太长）：`bad_params`，什么都不记。
   - 同一个命令编号再发只算一次，回应和头一次一样。
2. **内核的命令 `Respond`**：
   - 会话正在跑一轮：拒，`turn_running`（O-14 下改成并进去）。
   - `to` 里有不是这个会话里旁听的 `message.user` 的：拒，新原因码 `not_ambient`；有已经当过触发的：拒，新原因码 `already_answered`。拒绝带上是哪几条（`Outcome::Rejected` 多一格 `about`），协议的错误 `data` 写成 `{"messages": [序号…]}`。
   - 合的：开一轮，`turn.started` 多一格 `triggers`（排好的序号），`trigger` 是最后一条；内核的事实照旧，桥的几块接在它们后面，都在触发前面（`08-上下文投影.md` C2）。不过回合闸（还没有）。
3. **账本**：记下哪些是旁听的 `message.user`、哪些当过触发（`turn.started` 的 `trigger`、`triggers`）；`turn.started` 带 `triggers` 的，查每一条都是旁听的、没当过触发的、排好的、最后一条就是 `trigger`。撤掉的回合当过的照样算当过。
4. **渲染**：
   - `triggers` 那几条在回合开始的地方渲染：群会话里是一行一条（O-13 中），别的照原样；放法和 `session.send` 开的触发一样，前面是事实、群聊近况。
   - 群聊近况改照回合开始的那一条算界：收上一个由人的消息开的回合开始以后、这一轮开始以前的旁听消息，不收当过触发的。`session.send` 开的回合，渲染出来和 O-13（下）一字不差。
5. **随机测试**：内核的随机会话多一种输入 `Respond`，不变量照查。

### 主会话定的技术细节

1. 开一轮的那几条照回合开始的那一条渲染，不照它们自己在日志里的位置：它们记下时是旁听的，以前的请求里没有；挪到前面去渲染，会改动已经发过的请求，前缀接不上。近况的界也改照回合开始的那一条，桥判得慢、交的是更早的几条也不乱。
2. 群聊近况在回合开始那一组里单占一格（`Place::Lead`），排在事实后面、触发前面；`session.send` 开的回合字节不变。
3. `to` 去重、排好，不拒重复（桥照序号交，别依赖先后：2026-10-09 和通讯平台的会话定）。
4. 原因码只有两个新的；`to` 空的协议这一层拒，内核也拒（`empty_message`）以防漏网。

### 不做什么

- 正在跑一轮时并进去、`turn.joined`、这一轮没再请求就结束时接着开：O-14（下）。
- 回合闸：还没有。

### 验收

1. 测试先写，改之前红：闲着时照几条开一轮、事实在前、`triggers` 排好去重；正忙的拒；不是旁听的、当过触发的拒，带上是哪几条；协议写错的什么都不记；命令编号再发只算一次；账本查 `triggers`；渲染：触发的几条在回合开始的地方、群会话里一行一条、近况不收当过触发的、`session.send` 开的回合一字不差；载入以后照样；随机测试多 `Respond`。
2. 手写变异；`cargo xtask check` 八项；三台 CI 和长跑。
