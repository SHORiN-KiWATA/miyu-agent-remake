## 施工单 8-31：供应商图标

状态：2026-10-11 合了（ed5968fa，CI run 1676；第一次 Windows 起核心超时，重跑绿了）。网页的会话转来，项目主人 2026-10-11 定：供应商带图标，彩色的用 lobe-icons 的彩色版，别的用 models.dev 的单色版（对比过两套的样子）。

### 这一步做什么

1. 对照表 `resources/models/logos.json`：models.dev 的地址、lobe-icons 钉住版本的地址、有彩色版的几家（deepseek、openrouter、zhipuai、alibaba、alibaba-cn、minimax、minimax-cn）。
2. 纯逻辑 `miyu-models` 的 `logos.rs`：读表、哪一家从哪拉、拉到的收不收（UTF-8、32 KiB、是 SVG、不是 models.dev 的默认图）。
3. 拉和存 `miyu-core` 的 `models/logos.rs`：节奏同目录，另一个任务；先认默认图，再拉目录里每一家的（同时 8 张）；存进 `<缓存目录>/models/logos/`，整份换；核心起来时先换上缓存里的。
4. 交给头：`ModelData` 多一份图标；`provider.catalog`（含 `featured`）每一项、`model.list` 每一家多 `logo: {"svg", "tint"} | null`，`model.list` 照认出来的目录那一家给。
5. 图纸 `models.md`「图标」、`protocol.md`、`licenses.md`（两份 MIT、商标归各自所有者）。

### 验收

- `miyu-models` 的 `logos/tests.rs`：出厂的表读得成、选得对来源；收不收的几种。
- `miyu-core` 的 `tests/logos.rs`（假服务器）：单色的存进缓存、换上、先认默认图；默认图、不是 SVG 的当没有；彩色的从 lobe 拉、不和默认图比；默认图拉不到的什么都不换。
- `cargo xtask check` 八项；三台 CI。网页的会话在 8771 实测引导、设置页、换模型菜单三处。
