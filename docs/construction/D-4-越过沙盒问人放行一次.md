## 施工单 D-4：越过沙盒问人放行一次

状态：待验收（2026-10-07 写、施工完；项目主人同一天在终端界面验收时定，照 Claude Code 的 `dangerouslyDisableSandbox`；经终端界面的会话转来；D-1 补的确认说明带标题和命令并进这一步；技术细节主会话定）。D-3 合进去以后变基：工具说明的预算、登记簿和 D-3 改的是同几处。

### 目的

助手在的机器上（Linux 的 Landlock、macOS 的 Seatbelt），工作区这一级的命令在沙盒里跑、不问人。命令要写工作区以外（例如 `~/Downloads/x.txt`）时只会失败（`EPERM`，「权限不够」），人看不到确认。`11-权限与沙盒.md` A1 说「要越过沙盒的，才问人」，这条路还没有（`session/guard.md`「还没有的」第一条）。

改成：`shell` 多一个可选的布尔参数，意思是「这一次在沙盒外跑」。写了它的调用，工作区这一级问人（`tool.approval_requested`，`access: execute`）；允许了，这一次不套沙盒；拒绝了，她拿到平常的拒绝。没写的照旧在沙盒里跑、不问。

### 项目主人否掉的

- 核心看输出里的 `EPERM` 自己判、问人要不要重跑：靠猜，脆。
- 每条可能出工作区的命令先问：问得太多。

### 蓝图改哪几节

- `tools/shell.md`：参数表多一行；「怎么走」写明谁决定不套沙盒（执行器，不是工具自己）；「守着它的」。
- `session/guard.md`：第四节「不报路径的调用」多一种：要在沙盒外跑的执行；第五节说明（`detail`）执行类的多 `title`、`command`、`sandbox`；「还没有的」第一条去掉后一半。
- `kernel/events-bodies.md`、`protocol.md`：`tool.approval_requested` 的 `detail` 例子。
- `05-内核接口.md` 第六节（工具报给链的）、`11-权限与沙盒.md` 第二节：记下这一步。
- `26-提示词.md` 第十节：新参数的说明、只读时的拒绝那一句，量 token、登记；`10-自带软件.md` 第九节预算。

### 定了的（技术细节，主会话定）

1. **参数名 `outside_sandbox`**：照别的参数用下划线；不叫 `dangerously…`：问人那一步就是挡危险的。说明一句：`Run it outside the sandbox once the user approves, only after the sandbox blocked it.`
2. **工具只报，执行器决定**：`miyu_tool::Tool` 多一个默认否的 `outside_sandbox(&Call) -> bool`，`shell` 照参数报。权限策略照它判要不要问；执行器照它不写沙盒的规格。工具自己不看这个参数决定套不套：套不套从来是执行器的事（`crate::sandbox`）。
3. **怎么判**（实际生效的那一级）：
   - 完全放开：放行，本来就不套沙盒。
   - 工作区：问人，不管沙盒能不能用；不提规则（`rule` 不写），只能选允许这一次或者拒绝：一次放开整个沙盒，不该一劳永逸（终端界面说了没有规则时自己藏掉「本会话都允许」）。
   - 只读：拒绝，照用现成的只读那一句（`core/tool-results/read-only.txt`：`The call was not run: the session is read-only.`），不加新的字。
4. **说明（`detail`）**：执行类的确认（这一步的、沙盒用不了时每条命令的）都写成 `{"command": …, "sandbox": false, "title": …, "tool": "shell"}`。`title` 是 `description`，`command` 原样，`sandbox: false` 说这一次不在沙盒里跑（沙盒用不了时也是假）。工具多一个默认空的 `asking(&Call) -> Map`，交给说明的几格，权限策略并进去；`shell` 交 `title`、`command`。这就是 D-1 补。
5. **后台的照样**：`run_in_background` 和它一起写的，问过、允许了，后台命令在沙盒外跑；后台命令保持启动时的样子（`11-权限与沙盒.md` 第二节）。
6. **放行过的规则管不到它**：本会话放行过的只管文件工具的路径，没有规则可对，每次都问。
7. **工具面**：参数常驻（工具面会话内字节恒定）；新会话的前缀变，开着的会话照快照，旧快照里没有这个参数。

### 不做什么

- 照命令开头的放行规则（`git push` 以后都放）：`guard.md`「还没有的」留着。
- 输出里看到 `EPERM` 提醒她可以越过沙盒：先实测说明够不够，不够再说（「给模型的字：非必要不加」）。

### 验收

1. 测试先写，改之前红：
   - 权限策略：三级各判一遍；工作区沙盒能用、用不了都问，`rule` 没有，`detail` 逐字节比；只读拒绝那一句；没写的照旧放行；放行过的规则不放它。
   - 执行器：写了、允许了的调用不带沙盒的规格，没写的照旧带（假助手看收到的）。
   - 工具：`outside_sandbox`、`asking` 照参数报；参数写成字符串的照参数格式修正。
   - 协议：真核心上她写了这个参数，头收到 `tool.approval_requested`，回 `once` 以后命令在沙盒外跑完（Linux 上真助手：写得了工作区以外的临时目录），回 `deny` 她拿到拒绝。
2. 手写变异 12 个左右，全被逮住；`cargo xtask check` 八项；三台机器的 CI 和长跑。
3. 给模型的字：开发端点实测新参数说明、只读那一句的 token，登记；工具说明预算照实测改。
4. 真模型：开发端点上让她往工作区以外写一个文件，看她被沙盒挡下以后会不会自己写 `outside_sandbox` 再试；不会的，回来商量要不要在输出里提醒。
5. 合进 main 以后告诉两个头：`detail` 的形状、`outside_sandbox`、没有规则。

### 风险

- 她不该越过时也写它：每次都问人，最坏是多问一次；问的时候抽屉写明「在沙盒外跑」。
- 执行器信了工具报的就不套沙盒：只有问过人、人允许了才走得到执行（只读拒绝、工作区一定问、完全放开本来就不套）。测试守着「工作区不问就跑不到」。

### 施工结果（2026-10-07 主会话）

1. 测试先写，改之前红：`crates/miyu-session/tests/outside_sandbox.rs` 八条（允许一次的那一次不带沙盒的规格、没报的照旧带也不问；拒绝的没跑；没人能确认的拒绝；只读不问、拒绝；完全放开不问；碰数据根的照拒、不问；沙盒用不了时每条命令都问、说明带标题和命令；Unix 上真经助手跑 `shell`，没写的写不进工作区以外、写了的允许以后写得进），改之前四条红（完全放开、数据根那两条本来就成立）；`guard/tests.rs` 一条（说明并进工具交的几格、工具名盖不过、执行类才写 `sandbox`）；`miyu-basesystem/tests/shell.rs` 一条（`outside_sandbox`、`asking` 照参数报）。原有的一条照新的说明改：沙盒用不了时是 `{"sandbox":false,"tool":"shell"}`。
2. 工具接口多两个默认的方法（`Tool::outside_sandbox`、`Tool::asking`），假工具照参数报。权限策略判完路径再看要不要在沙盒外跑（`beyond`）：拒绝的照拒、完全放开照判的、只读拒绝、工作区问人不提规则。执行器只在工具报了时不写规格。
3. 协议这一层一个字节没改：`tool.approval_requested` 照原样推，`session.answer` 是 D-1 的。没另写真核心的协议测试：会话这一层真经助手跑的那一条已经从调用一直走到写进文件。
4. 给模型的字：只有参数的说明一句，照开发端点量 +35 个 token（`shell` 185 → 220），139 字节，在 9200 的预算里（`26-提示词.md` 第十节）。
5. 手写变异 14 个。头一轮漏了一个（沙盒用不了时 `paths` 没把 `asking` 交给 `untargeted`：单元测试直接调的 `untargeted`，接线没人守），补了一条集成测试，变异下红、原样绿。`cargo xtask check` 八项全过。
6. 真模型实测（2026-10-07 主会话，magpie 网关的 `cline-pass/deepseek-v4.1-flash`，`cargo xtask dev-home` 造的数据根，核心带着助手，自己写的小客户端当头、要确认的允许一次）：叫她「用一条 shell 命令把 notes.txt 复制到工作区以外的一个目录」，没提沙盒。她头一次在沙盒里跑，`权限不够`；接着看了目录本身对用户可写，说是沙盒挡的，写了 `outside_sandbox` 重跑同一条，说明是 `{"command":"cp notes.txt …/outside/","sandbox":false,"title":"Copy notes.txt outside sandbox","tool":"shell"}`；允许一次以后复制成了，她再在沙盒里比对文件一致。最后告诉人第一次被沙盒拒了、经批准在沙盒外重跑。说明一句就够，输出里不用另加提醒。
