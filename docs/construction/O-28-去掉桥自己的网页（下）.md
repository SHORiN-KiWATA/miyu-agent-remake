**施工时碰到的**：

1. `control.rs`（`start`、`stop`、`restart`、`status`）照终端的样子连核心用的就是 `miyu_webserve::open::Core`，施工单写「桥用不上了」不对。整个去掉要么抄一份进桥（18 第三节「抽成两边共用的库，不抄一份」），要么挪进 `miyu-ipc`（动网页软件用的 crate）。照推荐留着依赖、只用这两样，给页面、`/ws`、Host 那几样不再用（`onebot.md` 第一条「施工时定的」第 166 条，`webserve.md`「谁用」改了）。请主会话过目，要改成抄一份或挪进 `miyu-ipc` 的再开一步。
2. 推来的端口被占：原来靠页面调 `/apply` 再试一次。`/apply` 去掉以后不再另试，人在后台页上换一个再存（后台页本来就这样说，第 167 条）。
3. 桥手里的状态原来在 WebUI 的 `Web` 上：挪进 `running.rs` 的 `Running`（后台页的 `status`、状态文件、换端口共用），换端口挪进 `running/rebind.rs`（第 168 条）。状态文件去掉 `web`；`status` 说 NapCat 的地址（`status/listen`），接一句「设置和状态在网页的软件后台：miyu web --package onebot」（`status/page`，三种语言，第 169 条）；没令牌那一句改成到网页的软件后台生成（第 171 条）。
4. 包的程序不在主程序旁边的当没装、配置项不拼：测「`onebot.web` 报不认识的键」要先把 `miyu-onebot` 链到测试程序旁边（同 `Home::spawning`），不然连 `onebot.listen` 也不认识。
