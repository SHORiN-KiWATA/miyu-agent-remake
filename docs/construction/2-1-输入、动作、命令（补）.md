## 施工单 2-1（补）：重启前后，同一个编号再来回应一样

状态：已完成（2026-10-07 写、施工完；CI run 1021 三台和长跑全绿；O-3 写测试时撞见，项目主人同一天定统一成都只回原来那一条）。

### 目的

同一个命令编号再发只生效一次（不变量 9），重启以后照样。可回应附的序号前后不一样：没重启时发消息回的是 `message.user` 那一条；核心重启、载入以后，回的是 `cause` 是这个编号的全部，连同它开的那一轮。桥断线重连、平台重发时，同一句话两次拿到的回应不一样。

### 蓝图改哪几节

- `kernel/session.md`「命令和回应」第 4 条：载入时照日志重建的规矩。

### 定了的（技术细节，主会话定）

1. 载入时，一个编号的事件在它开的头一个 `turn.started` 前面截住：发消息、回报、撤销、重做（新的一轮的开头不在里面）都对得上「命令和回应」第 3 条。
2. 头一条就是 `turn.started` 的（手动压缩、清空）只留它：第 3 条说的就是「那一轮的 `turn.started`」。
