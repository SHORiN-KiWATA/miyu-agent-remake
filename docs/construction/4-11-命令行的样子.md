## 施工单 4-11：命令行的样子

状态：待施工（2026-09-28 项目主人试玩 M4 以后提的，排在 M5 前面）。

### 目的

- `miyu ask` 的每一步照 opencode 的样子印：前面一个符号；命令写成 `$ 命令`，下面印她看到的输出；编辑下面印改动。
- `-h` 一页说全，参数写错时每种错说一句人话，中文界面里不再混着 clap 的英文。
- `MIYU_HOME`、`MIYU_RESOURCES` 认开头的 `~`。

  - 「对外的样子」加短写 `-c`、`-s`。
  - 「样子：`--format text`」改成新样子，写清每一步的符号、名字、结果怎么写。命令、编辑这两种是一块：标题下面印内容，前后空一行。样本跟着换。
  - 帮助页中文、英文各一页。
- `cli/main.md`：
  - 帮助页换成自己写的。

  - 「还没有的」记下会话怎么接。

- `store/resources.md`：
  - `Face` 多两格：`icon` 是符号，`block` 是标题下面印什么。

- `store.md`：`MIYU_HOME` 认开头的 `~`。

合进来之前，新的样子和帮助页先写成普通的块；合进来时标成「样本」，门禁逐字节比。这样 main 在这中间一直是绿的。

### 定了的

2026-09-28 项目主人定：
1. 命令、编辑下面的内容全部照印：命令印她看到的全部输出，编辑印改动。命令的输出最多 3 万字，是工具本来就截成头尾的那一份。
2. 每一步前面写符号，名字照界面语言，从显示名表里取。
3. 帮助页自己写，一页说全；`--continue`、`--session` 加短写 `-c`、`-s`，和 opencode 一样。参数写错时的报错也跟界面语言，每种一句，不啰唆。
4. 这一步排在 M5 前面，顺路认 `~`。

### 不做什么

- 会话怎么接：现在每次 `miyu ask` 开一个一次性会话，`--continue`、`undo`、`redo` 管的都是上一次 `miyu ask` 开的那个。项目主人 2026-09-28 定：做头的时候再改。
- `miyu undo` 印的样子不动。
- 命令不边跑边印：做完一步再印那一块，几条命令同时跑时输出就不会搅在一起。
- 界面的字挪出代码：等界面语言那一步。

### 验收（项目主人照着做）

在一个新开的终端里，用你自己的 key：

```bash
bash ~/.cache/miyu-m4/setup.sh
export MIYU_HOME=/tmp/miyu-m4/home
export MIYU_RESOURCES='~/Documents/github/miyu-agent-remake/resources'
export DEEPSEEK_API_KEY=你的 key
M=~/Documents/github/miyu-agent-remake/.worktrees/4-11-cli-look/target/release/miyu
cd /tmp/miyu-m4/repo
```

`MIYU_RESOURCES` 故意加了引号，开头的 `~` 不让 shell 展开，交给 Miyu 自己认。

1. `$M ask "cargo test 没过，找出原因修好，再跑一遍测试确认"`，看这几样：
   - 命令印成 `$ cargo test …`，下面是她看到的输出，前后各空一行；
   - 读文件是 `→ 读取 src/lib.rs · 24 行`；
   - 编辑是 `← 编辑 src/lib.rs · 改了 1 处`，下面 `-` 行红、`+` 行绿；
   - 核心照常起来，不报「要写绝对路径」。
2. `$M -h`、`$M ask -h`、`$M undo -h`：看一页说全、没有英文。再看英文的：`LANG=en_US.UTF-8 $M -h`。
3. 参数写错时，每种只说一句，退出码 2（`echo $?`）：
   - `$M ask`
   - `$M ask --bogus hi`
   - `$M ask -s x -c hi`
   - `$M ask --format xml hi`
   - `$M undo --session`
   - `$M undo extra`
4. `$M ask -c "刚才改了哪里"`：接着上一次说。

### 风险

- 命令的输出里有终端控制序列（颜色、改标题、写剪贴板）：CSI、OSC 两种整段去掉，别的控制字符换成 `�`，制表符照留。
- 输出长的命令（构建日志）会刷掉好几屏：照定的全部照印。
- clap 升级以后报错里带的信息变了：测试钉住每一种错说的那一句。
