## 施工单 R-7（补）：现在就整理记忆（/dream）

状态：施工中（2026-10-10 写；项目主人 2026-10-10 定做、照推荐：命令叫 `/dream`、界面写「整理记忆」、回执只报数字、现在插一小步；形状 2026-10-10 核心的主会话同意，后台答照它的放法：命令表登记哪条命令在后台答）。

### 目的

合并（R-7 上）照定时在后台悄悄跑。人想现在就让她把记忆理一遍：刚聊完一大段、刚纠正了好几件事。理完回一句数字，人当场看得到她改了多少。

### 蓝图改哪几节

- `memory.md`：第七条多一款「现在就整理」（先抽当前会话没抽的、不看间隔和会话数、同一间一把锁照旧、回几样数）；「协议」多 `memory.dream`；「在哪」「守着它的」。
- `protocol.md`：`memory.dream`（参数、回应、拒绝、在后台答）；斜杠命令 `/dream`；拒绝的表多 `memory_busy`；「一个连接」第 1 条在后台答的多这两样。
- `commands.md` 或 `protocol.md` 的命令表：`/dream`（名字、说明、能不能用照 `/remember` 的判法）。
- `cli/memory.md`：`miyu memory dream`。

### 定了的（技术细节照推荐定）

1. **协议 `memory.dream {persona? | session?}`**：找哪一间同 `memory.*`（没装人格记忆的 `memory_not_installed`，没有记忆的 `memory_unavailable`）。带 `session` 的先叫那个会话把还没抽的那一段抽了（不等闲 3 分钟、答了一轮就算，那个会话正忙的不抽）；然后不看 `memory.merge_every`、`memory.merge_sessions`，现在就合（放不下的接着合完）。回 `{"given", "revised", "retired", "summary"}`（交进去几条、改了几条、作废几条、摘要换没换）；没有要整理的 `given` 是 0。这一间正在合的回 `memory_busy`（-32010）；没合成的回 `dream_failed`（`data.message` 是英文的一句为什么）。在后台答（`methods::answered_later`）：几秒到十几秒，同一个连接后面的请求不等它；`call_later` 多收这个连接的 `Peer`（`/dream` 的回执照它的语言写）；`memory.*` 照旧认管理员、用不上 `Caller`，不交（不为以后写代码）。
2. **斜杠命令 `/dream`**（不带字）：能不能用照 `/remember`（会话开着记忆）；做的就是带这个会话的 `memory.dream`；回执 `commands/dreamed`：「整理完了：看了 {given} 条，改了 {revised} 条，作废 {retired} 条。」，摘要换了的 `commands/dreamed-summary`（句号前多「，摘要更新了」），没有要整理的 `commands/dreamed-nothing`：「没有要整理的。」。在后台答：`Slash` 多 `later()`，只有 `Dream` 是真，`methods::answered_later` 收整条请求，`command.run` 的照命令表问，别的照旧只看方法名；`/clear`、`/stop` 这些照旧按顺序答。
3. **会话那一层**：`Handle::dream()` 叫 actor 照现在的抽取跑一次（同闹钟响了的那一条路，只是不看闲没闲够、答了一轮就算），抽完了（或者没得抽）再合；`Keeper::dream(...)` 是不经会话的那一路（`persona`）。合并多一条能等的「现在就合」，同一间一把锁照旧：锁着的交回忙。
4. **命令行 `miyu memory dream`**：发 `memory.dream`（`--persona`、`-s` 同别的子命令），印同一句回执。
