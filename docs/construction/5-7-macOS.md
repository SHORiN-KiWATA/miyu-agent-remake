## 施工单 5-7：macOS

状态：施工中（2026-09-28）。

### 目的

macOS 上沙盒真的管住读写：助手把规格写成一份 Seatbelt 配置，装到自己身上，再换成命令。文件照规格能读、能写、只读、藏起来，`.git`、数据根改个名也绕不过去。网络不管（2026-09-29 项目主人定）。探测报 `seatbelt`。

### 蓝图改哪几节

- 新的一页 `sandbox/macos.md`：配置的底子、照规格生成的规则和先后、换成真实的位置、装上、探测、收紧不成的几种说法。
- `sandbox.md` 这一步不改：说「还不收紧」的几处，主会话合并时一起改。
- 设计 `11-权限与沙盒.md` 第六节 macOS、A8：为什么助手在自己身上装配置、不经 `sandbox-exec`；为什么能替命令读写别处的系统服务照样挡。

### 要拍板的

1. 能替命令到别处读写的系统服务挡不挡：`open` 打开别的程序、`osascript` 叫别的程序做事、`launchctl` 起任务，都在沙盒外面跑，一条命令就能读写任何地方；偏好设置、钥匙串的服务也替命令读东西。推荐：挡（配置照「没写到的一律不许」，只放行跑命令、联网要的服务）。代价：沙盒里 `open`、`osascript`、钥匙串用不了，要用就越过沙盒（M8）。Linux 上同一类的口子是 D-Bus（`systemd-run --user`），不禁 Unix 套接字以后挡不住。

### 不做什么

- 网络、本机的端口、Unix 套接字：不管（2026-09-29 项目主人定）。
- 规格里放哪些路径：权限策略，5-4。macOS 上到时一起看：`/tmp` 要不要能写（`TMPDIR` 在 `/var/folders/…`）、`~/Library/Caches` 下工具链的缓存、还不存在的 `.git` 要不要挡住新建。
- 核心给调用带规格、沙盒用不了时问人：5-4。

### 风险

- 本机没有 Mac，Seatbelt 的规矩只能在 CI 上量。第二阶段先在分支上跑一轮只在 macOS 上的实验：后面的规则压过前面的、套两层时的原话、硬链接绕不绕得过只读、上级的元数据要不要放行、读不了的目录里找程序报什么（顺着 `PATH` 找）、联网要哪些系统服务、中文注释进不进得了配置。量出来和蓝图不一样的，先改蓝图再写代码。
- `sandbox_init_with_parameters` 不在公开的头文件里（`sandbox-exec -D` 用的就是它）：苹果哪天改了，探测报不出 `seatbelt`，核心照沙盒用不了办。
- 不管 Unix 套接字、本机的端口：开着 Docker 的机器上，沙盒里的命令能经 Docker 读写任何地方；本机端口上能替人跑命令的服务（例如旧版 Miyu 的 8300）也一样。
- 连 HTTPS 的测试要上网（CI 上连 `github.com`），没网的 Mac 上它会红。
- `tests/run.rs` 用的是什么都不许读的空规格：真收紧以后，macOS 上 `sh` 都起不来。要改成能读整个根目录、能写临时目录（Linux 的 5-2 也会撞上），谁改由主会话定。
