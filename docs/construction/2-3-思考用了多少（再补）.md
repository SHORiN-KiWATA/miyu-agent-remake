## 施工单 2-3（再补）：思考用了多少 token

状态：合了（7412309f，run 1358；2026-10-09 写；终端的会话要的：一段思考现在只能写用时；技术细节主会话定）。

### 目的

头在一段思考的收尾写「思考 N 词元」。供应商报了思考用了多少，核心没记下来。

### 这一步做什么

1. `model.called` 的 `usage`（和 `model.call` 回应的 `usage`）多一格可以没有的 `reasoning`：输出里思考占了多少，已经算在 `output` 里。
2. 驱动照各家的写法取：OpenAI 兼容对话接口 `completion_tokens_details.reasoning_tokens`（DeepSeek 也报，2026-10-09 实测 `deepseek-flash`、`deepseek-reasoner` 都有），Responses `output_tokens_details.reasoning_tokens`；Anthropic 不另报，不写。
3. 以前的日志没有这一格，读进来再写出去一字不差。

### 主会话定的技术细节

1. 报的是 0 的当没报：不想、不会想的模型每次请求都写一个 0 没用。
2. 一次请求一份：一次请求的思考块对一条 `model.called`（交错着调工具的，每一步各一次请求）。用量汇总、金额照旧四项，不另算思考（思考照输出计价）。

### 验收

1. 测试先写，改之前红：两家流的样本解出来带 `reasoning`（DeepSeek 20、Responses 100），报 0 的不带；`model.called` 带着的读写一字不差，旧的照旧。
2. 手写变异（6 处逮住 5 处；漏的是去掉 `#[serde(default)]`：serde 读 `Option` 的格本来就把缺的当没有，这一句照全仓的写法留着）；`cargo xtask check` 八项；三台 CI 和长跑。
