### 目的

撤销：你选中一轮，这一轮和它以后的全撤掉，她从此看不到，就跟没说过一样。在你发下一句之前，撤错了还能恢复，撤掉的几轮原样回来，她看到的一个字节都不变。

顺带修两处：有效历史撤一轮时，漏了上一轮排着队、被这一轮接过去的几句话；有计划的重启连着 4 轮不接以后，你开口开的那一轮，计数没从头数。

### 拍板的

- **你发下一句之前能恢复**：项目主人 2026-09-26 选「要，发下一句之前能恢复」，备注：「也就是undo掉undo这个操作？我觉得是可以的，因为有的时候会错误地undo掉不该undo的东西。这个反正是在拼装之前的操作，应该不难做吧？我记得opencode有这个功能，默认快捷键是ctrl+r，可以恢复undo的东西。」
- **从选中的那一轮起往后全撤**：问恢复时，两个选项的预览都写着「这句和后面的都撤掉」，项目主人选的那项照这样做。
- 先读了三家的源码（2026-09-26，codex d7b07d4、opencode 2.0.8、Claude Code 2.1.280）：
  - codex：两下 Esc 选一句，从那一轮起往后全撤，只在空闲时能撤；那句回到输入框；文件不动；没有重做。另起一份日志指向留下的那一段，她看不到撤过。
  - opencode v2：从某条消息起往后先藏起来，下一句或者压缩时才真删（`session.revert.staged|cleared|committed` 三种事件）。忙着的时候服务端拒绝，界面先打断再撤；那句回到输入框；默认连文件一起恢复（隐藏的 git 快照）。`/redo` 恢复：终端界面一次全回来，网页一次往前一句。能恢复的时候，后台任务的回报不开回合。
  - Claude Code：`/rewind` 或两下 Esc 选一句，可以只恢复对话、只恢复代码，或者都恢复；忙着时先取消；那句回到输入框；编辑类工具改过的文件有备份；没有重做；日志只追加，她看不到撤过。

### 我定的

- **有回合在进行时撤销，拒绝**：原因码 `turn_running`，头先打断再撤。三家都不在跑着的时候直接撤。
- **跟着撤的消息按回合算，不按「她听没听到」算**：试过按「这一轮之前的请求有没有看到」算，探针日志里就出错：35 号那一轮出错了、日志里没有请求的记录，撤 38 号会把 34 号「列一下 tests 目录」一起撤掉，可 45 号「换个问法」正是冲着 34 号说的。
- **由上一轮排着的消息接着开的那一轮，把上一轮结束时还排着的几句一起带走**：之前只带走触发它的最后一句，前面几句留在历史里，她就会看到没人回的话。崩了以后留下来的排着的消息不算：那一轮以 `aborted` 结束，它们排在那条结束前面，归那一轮。
- **恢复是一种新事件 `turn.unreverted`**，不去改 `turn.reverted`：撤销、恢复都是事件（03 第一节第 2 条）。英文名不用 restore：10 里「恢复」已经指撤销时把文件写回去；revert/unrevert 是 opencode 的叫法。
- **一次恢复一次撤销，从最近的往前**：照「undo掉undo这个操作」。连着撤了两次的，恢复两次。
- **下一轮开始了（不管是谁开的）、压缩过，就不能再恢复**：恢复的几轮要回到原来的位置；中间要是发过请求，她就是看着没有它们的历史说的话，放回去前后对不上。
- **账本只许撤「某一轮和它以后的全部」**：之前的账本允许单独撤中间的一轮，也允许同一轮撤两次。
- **撤销被拒分三种原因**：有回合在进行、不在有效历史里、压缩掉了（头可以提示去分叉）。序号落在最近一次压缩替代掉的范围里的，都算压缩掉了。
- **重启计数，不是接着干的那一轮从头数**：2-8（上）的测试全是连着的重启，没有「你开口」的那一轮，漏了。接着干的那一轮由被打断那一轮排着的最后一句、或者那条结束触发，照这个认。
- **被重启打断以后又撤销过的，载入时不接**：你已经动过它了。
