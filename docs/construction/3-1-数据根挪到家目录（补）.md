## 施工单 3-1：数据根挪到 `~/.miyu`（补）

状态：已完成（2026-09-26：三台机器的 CI 全绿、长跑也绿、测试全过，照施工方案第一节第 1 条算验收通过）。

### 目的

数据根的默认位置从 XDG 那一套改到家目录的 `.miyu`，三个平台一个说法；顶层放一个标记文件，认不出是自己的数据根就不碰它。旧版 Miyu 也放在 `~/.miyu`：新版在这台机器上一个字节都不动它，直到迁过来。

### 拍板的

- **放 `~/.miyu`**：项目主人 2026-09-26 问「关于目录，你觉得是用xdg更好还是放.miyu？」，选了「~/.miyu（推荐）」，连同「数据根上放标记文件，认不出是自己的就停下，不碰旧版的数据」。
- 当时给的理由：XDG 的好处在把配置、数据、状态分开放，我们已经定了一个数据根（S6），照 XDG 的话配置也落在 `~/.local/share` 里，没人去那儿找；一个目录好找、好备份、好搬家；和 `~/.claude`、`~/.codex` 一个样子。旧版就是 `~/.miyu`；opencode 照 XDG。
- 项目主人接着提了旧版到新版的迁移（「还有一个很重要的事情是旧miyu到新miyu的迁移问题」）：另画图纸，先盘点旧版的数据，再带着选项问。这一步只做到「不碰」。

### 图纸

- `07-存储.md` 第二节，这一步改的：默认位置的表；「认得出自己的数据根才动它」一条；目录布局里多了 `.miyu-root`；顶层不放 `config.toml`，免得被当成项目配置。第十一节 S6 记下这个决定和没选的两样。
- `12-进程形态与分发.md` 第三节：安装脚本不往数据根里放程序，那一句跟着改。

### 做什么

| 文件 | 装什么 |
|---|---|
| `crates/miyu-store/src/env.rs` | 快照里去掉 `XDG_DATA_HOME`：数据根不再看它 |
| `crates/miyu-store/src/root.rs` | 三个平台的数据根都是家目录的 `.miyu`；缓存不变。建骨架先看标记：没有目录、空目录，建好写标记；有标记的照常；不是空的又没有标记的，报错，里面什么都不建 |
| 测试 | 默认位置改了的那几条跟着改；标记的几种情形 |
| 施工图 | 3-1（补）那一张，步数多一步 |

### 不做什么

- 从旧版迁过来：另画图纸（`docs/designs/` 里新的一份），先盘点。
- 标记里的布局版本号怎么用：现在只认有没有；以后布局要变，再定怎么读它。

### 我定的

- **标记文件叫 `.miyu-root`，写一行人看得懂的字**：「This directory is a Miyu data root (layout 1).」。现在只认它在不在。
- **「不是空的」照目录里有没有任何东西算**：连隐藏文件也算。宁可多停一回，不往别人的目录里建东西。
- **报错写明是哪个目录，说清楚怎么办**：设 `MIYU_HOME` 指到别处，或者先迁过来。说「像是旧版 Miyu 的数据」只在目录里有旧版特有的东西时说，现在认顶层的 `config/`：旧版的配置目录就是 `~/.miyu/config`（旧版 `crates/miyu-base/src/paths/mod.rs`）。认不出是什么的，只说「这里有别的东西」。这只影响报错怎么说，认不认得出都不碰它；盘点完了，迁移那一步再添。
- **Windows 的数据根用用户目录**（`%USERPROFILE%\.miyu`，标准库的家目录就是它），缓存还用 `%LOCALAPPDATA%`。

### 验收

1. `step/3-1b-home` 分支的 CI：三台机器全绿，长跑也绿。
2. `cargo test`：
   - 三个平台的数据根都是家目录下的 `.miyu`；缓存照旧（Linux 看 `XDG_CACHE_HOME`）；`MIYU_HOME` 照样盖过。
   - 目录不存在：建好骨架、写下标记。空目录：同样。有标记的：照常，建两次不出错。
   - 不是空的又没有标记（放一个随便的文件、放一个像旧版的 `config/` 目录）：报错，里面什么都没多出来，原来的东西一个字节没变。
3. 故意改坏几处，测试变红：不认标记、不写标记、认不出旧版、数据根名字写错、隐藏文件不算、先建骨架再认标记。一共 6 处。
   - 新加 3 个测试（有标记的几种、不是我们的不碰、只有隐藏文件也不算空），改了 4 个（默认位置、缓存的 XDG、找不到家目录、空的和相对的）。
4. `cargo xtask check` 七项全过。

### 风险

- **这台机器上旧版正在用 `~/.miyu`**：测试一律在临时目录里；读进程环境的那个测试只找、不建。新版真在这台机器上跑之前，要么设 `MIYU_HOME`，要么先迁过来。
