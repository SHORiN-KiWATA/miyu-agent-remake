## 施工单 T-3：`miyu pkg` 命令

状态：2026-10-09 合了（51f52639，CI run 1476；设计 `30-插件框架.md` 第十二节第二阶段，2026-10-09 主会话排；名字照 `22-命令行.md` 第五节；技术细节主会话定）。

### 目的

装卸软件包（F-5）现在只有协议能做，头停着，人在终端里没法装卸。加一个命令行的管理命令，走同一组协议方法。

### 这一步做什么

1. `miyu pkg [list]`：一个一行，`<编号>  <名字>`，照编号排；卸掉了的出厂的标「已卸载」，写错的标哪里不对。`--format json` 原样印。
2. `miyu pkg install <清单|编号>`：带 `/`、`\`、以 `.toml` 结尾的是清单路径（相对的照现在的目录换成绝对的），别的是卸掉了的出厂的包的编号。
3. `miyu pkg remove <编号>`。
4. 帮助页中英两页，主程序的帮助页多一行。

### 不在这一步

- 搜索、软件源、停用：随软件源那一段。

### 蓝图改哪几节

新的 `cli/pkg.md`；`cli/main.md` 子命令那张表、帮助页。

### 验收

1. 测试先写：一行的样子、清单还是编号；真跑列、装、卸、装回来、拒绝的、`json`、帮助页。
2. 自己在沙盒数据根里当用户走一遍，看印出来的字。
3. 手写变异；`cargo xtask check` 八项；三台 CI 和长跑。
