## 施工单 5-8：Windows：装

状态：施工中（2026-09-28）。

### 目的

Windows 上装沙盒要的、要一次管理员权限的那件事做出来：建一个专用的低权限沙盒用户（藏起来），照这个用户装好网络封锁（只放行连本机代理，别的一律拦）。做成一个能单独调起的动作 `miyu sandbox setup`，卸载用 `miyu sandbox remove`；安装脚本（R12）做出来以后调它。每条命令具体怎么跑（受限令牌、单独桌面），是 5-9，不在这一步。

### 蓝图改哪几节

- 新的一页 `sandbox/windows.md`：`miyu sandbox setup`/`remove` 的样子和退出码；沙盒用户怎么建、怎么藏、密码怎么存；WFP 网络封锁怎么装、怎么撤；装好以后记的那份记录；要管理员那一次怎么弹。（README 分页表这一行由主会话合并时加。）
- 设计 `11-权限与沙盒.md` 第六节：加一句「为什么直接下 WFP 过滤器」——防火墙关着也照拦，少而准。


### 不做什么

- 每条命令怎么关进沙盒：受限令牌、访问控制、单独桌面、git 的 `safe.directory`——5-9。
- 权限策略给调用带规格、沙盒用不了改成问人——5-4。
- 安装脚本本身（R12）；这一步只做它以后要调的那个动作。
- Linux 上的 AppArmor 配置怎么装：5-3 定。
- 代理的端口段已经定了（`sandbox.md`「代理的端口段」，28480 到 28511），这一步照它下规则。

### 验收

CI 的 Windows 机器测不了要管理员、要真机的部分，在 Windows 虚拟机上实测：

1. 门禁 `cargo xtask check` 八项全过；两个目标的交叉 clippy 都过。
2. 单元测试：命令行解析、记录文件读写、WFP 过滤器拼出来的规格（GUID、层、按用户 SID 的条件）——不真装，只查拼出来的对不对；非 Windows 上 `setup`/`remove` 是空动作、退出 0。
3. 虚拟机上 `miyu sandbox setup`：沙盒用户建出来了、在登录界面藏着、是普通用户不是管理员；WFP 过滤器装上了（`netsh wfp show filters` 看得到）；照沙盒用户跑一条命令，连公网被拦、连本机代理端口通（代理还没有时先看连本机那一段的表现）。
4. `miyu sandbox remove`：用户没了、过滤器没了、记录文件清了；报告里写清虚拟机上还剩什么。
5. 管理员那一次弹窗：虚拟机的 UAC 设成了管理员免提示（`ConsentPromptBehaviorAdmin=0`），从 ssh 进去本就是提升过的，所以看不到弹窗；报告里说清默认 UAC 的桌面上才会弹一次，怎么在虚拟机桌面上验。

### 风险

- 虚拟机上防火墙三档都关着：用高层防火墙接口（COM）下的规则不生效，所以走 WFP（BFE 服务在跑，实测）。
- WFP 过滤器是持久的（重启还在）：卸载一定按稳定 GUID 删干净，测「装了又卸」不留东西。
- 沙盒用户的密码要存起来给 5-9 登录用：DPAPI 加密、存进数据根（沙盒读不到），用当前用户范围（比 codex 的机器范围窄）。
- `miyu sandbox` 子命令要动 `crates/miyu/src/main.rs` 的分发（可能和 5-4 同碰一个文件）：只加一条分发臂，别重排。
