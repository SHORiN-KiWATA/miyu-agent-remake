## 施工单 F-6（上）：软件包列表

状态：2026-10-10 合了（f1f9fd91，CI run 1521；设计 `30-插件框架.md` 第十三节，2026-10-10 项目主人定方向；图纸 `docs/blueprint/package-pages.md`，主会话起草，网页、终端、接入QQ 三个会话同一天对过）。

### 目的

「软件包」页改成装了的软件的列表，点进去是核心照清单生成的信息页；「接入」页去掉。这一步做列表和信息页要的核心这一边：清单的图标、后台页，列表的状态和开关，程序不在就当没装，包的配置项归包。后台页的文件和方法是 F-6 中。

### 这一步做什么

1. 清单多 `[package] icon`（Lucide 图标名）和 `[page] dir`（后台页在包目录里的子目录，只有扩展、内置包能写）；写法不对的 `bad_icon`、`bad_page_dir`。
2. `package.list` 每一项多 `icon`、`page`（目录里有 `index.html` 才带）、`status`、`enabled`。
3. 程序不在 `miyu` 旁边的扩展、小程序当没装：
   - 配置项不进配置清单；功能不进预设；`extension.enable` 拒绝 `program_missing`；
   - 开着的在核心起来时不照登记缓存登记工具，记成停下。
   - 界面的程序不在，配置项照旧在（终端的会话提：开发时界面的程序不在 `miyu` 旁边）。
4. `package.enable`、`package.disable`：扩展开关进程；出厂的、不是必需的内置包关是卸掉、开是装回来；必需的 `package_required`，界面、小程序 `not_switchable`。
5. 包的配置项一律在「软件包」那一页、这个包那一组，`config.schema` 每一项多 `package`；`connections` 页去掉。
6. `miyu check` 对写了后台页、目录里没有 `index.html` 的报警告 `page_missing`。

### 不在这一步

- `package.file`、`package.call`、`package.methods`：F-6 中。
- 网页软件给后台页、框和网页之间的通道、`miyu web --package`：网页的会话。
- 接入QQ 的网页挪成后台页：接入QQ 的会话（O-28）。

### 蓝图改哪几节

`package-pages.md`（这一步做的几节标做了）；`packages.md` 的格式、种类那张表、配置项第 4 条、`package.list` 的表、`miyu check`、代码表；`protocol.md` 的方法表、`package.list`、新的 `package.enable`、`package.disable`、原因码两张表；`config.md` 的 `config.schema` 每一项的格；`extensions.md`「拉起」。

### 验收

1. 测试先写：清单两格的读法和报错；列表的四格；开关；程序不在当没装；`package`；`page_missing`。
2. 原来照「程序不在也算装了」写的测试照新规矩改：接入QQ 的程序不在测试程序旁边，它的配置项、`qq` 功能不再算；要「程序在」的用测试用的扩展。
3. 生成配置的样本照发行包的样子算，程序都在（`Packaged::as_released`），不照跑测试的这台机器，样本不变。
4. 手写变异；`cargo xtask check` 八项；三台 CI。

### 施工时定的

- 程序在不在照 `miyu_store::packages::locate`（只找 `miyu` 真实位置旁边的），每次用时查，不缓存：放回程序以后再开一次开关就认。
- 配置项、功能照「程序在不在」拼的那几处，生成样本、测出厂清单时交「都在」进去（`settle_with`、`Packaged::as_released`）：样本写的是发行包的样子。
- 新的原因码给人看的字照项目主人 2026-10-10 说的通用软件说法：「程序未安装。」「不能启用或停用。」
