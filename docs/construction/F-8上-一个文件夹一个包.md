## 施工单 F-8 上：一个文件夹一个包

状态：2026-10-11 合了（34fd67f9，CI run 1658）。设计 `31-软件包.md` 第二节、第三节第 1 条、第七节；项目主人 2026-10-11 定一个文件夹就是一个包。

### 起因

以前一个包是 `packages/<编号>.toml` 加同名目录，清单和文件分两处放，装的时候要两样一起拷。设计 31 照 pacman 改成一个文件夹一个包：文件夹名就是编号，清单是里面的 `package.toml`。设计第九节把第一步拆成两半：这一半只换放法；去掉 `kind`、照表认包带了什么，放到 F-8 上补。

### 这一步做什么

1. 读（`miyu-store` 的 `packages.rs`）：两层里每个合写法的文件夹，里面有 `package.toml` 的算一个包；`Found::path` 是那份清单，`files_dir` 是文件夹。
2. 装（`packages/install.rs`、`miyu-endpoint` 的 `packages/manage.rs`）：`package.install {"path"}` 收包目录，也收包目录里的 `package.toml`，整个文件夹拷进去，暂存、备份、换进去照旧。卸是删掉这个文件夹。
3. 以前的写法（`packages/migrate.rs`，核心起来读清单时跑）：家目录那一层的 `<编号>.toml` 挪进同名文件夹，改名 `package.toml`；文件夹里已经有一份的不覆盖，记 `WARN package not moved`；挪了的记 `INFO package moved`。
4. 出厂的挪好：`resources/packages/<编号>/package.toml`，`crates/miyu-embed/package/embed/package.toml`；网页读自己清单的路径跟着换。
5. `miyu check <文件>`：认 `packages/<编号>/package.toml`，包目录里别的文件、以前的 `<编号>.toml` 不认。
6. `miyu pkg install`：带 `/`、`\`，是 `.`、`..`，或以 `.toml` 结尾的是路径，相对的照当前目录接成绝对的，`.`、`..` 照字面去掉；帮助页两种语言跟着改。
7. 图纸 `packages.md`、`protocol.md`、`cli/pkg.md`、`cli/check.md`、`store/resources.md`、`onebot.md`、`web-ui.md`、`web-module.md`、`recall.md`；设计 31 第七节第 2 条照推荐定挪不成的只记警告。

### 验收

- `miyu-store`：`packages/migrate/tests.rs` 两条（挪进文件夹、原来的文件在、卸掉那一笔不动、挪过的再来不动；已经有的不覆盖、编号不合写法的不动）；`packages/tests.rs` 改成文件夹，不是文件夹的、文件夹里没有清单的、以前的 `<编号>.toml` 不算。
- `miyu-endpoint`：`packages_install.rs` 装的是包目录，升级以后旧文件不留、卸掉整个文件夹没了；`packages.rs` 新加 `an_old_layout_in_the_home_is_moved_when_read`，`check` 认得出包目录里的清单、认不出别的文件。
- `miyu-cli`：`pkg/tests.rs` 路径的几种写法；`miyu` 的 `tests/pkg.rs` 用 `./xpkg`、`bad/` 真装一遍。
- 变异：读清单时不挪、`check` 不看文件名两处各自报红。
- `cargo xtask check` 八项；三台 CI。
