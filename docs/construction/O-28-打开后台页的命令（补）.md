## 施工单 O-28（补）：`miyu onebot web` 打开后台页

状态：已完成（2026-10-10；项目主人 2026-10-10 定：`miyu onebot` 就是接入QQ 自己的命令，打开它的页面也该在里面，`miyu onebot web` 就好；`start` 的时候也印怎么打开）。

### 目的

O-28 下去掉了桥自己的网页，连 `miyu onebot web` 一起删了，打开后台页只剩通用的 `miyu web --package onebot`。用的人管接入QQ 用 `miyu onebot start/stop/status`，打开它的页面却要换一个命令，绕。这一步把 `miyu onebot web` 加回来：打开网页、直接到软件后台里接入QQ 的页面；`start`、`status` 都印一句「设置和状态：miyu onebot web」。

### 蓝图改哪几节

**`docs/blueprint/onebot.md`** 第一条 `miyu onebot` 子命令：加 `web`：照 `miyu web --package onebot` 打开（找 `miyu` 照转交的办法：`miyu onebot …` 是 `miyu` 转给旁边的 `miyu-onebot`，`miyu` 在 `miyu-onebot` 旁边），退出码、输出照 `miyu web` 的；`start` 起好了、`status` 末尾印「设置和状态在网页里：miyu onebot web」（三种语言），不再印 `miyu web --package onebot`。「施工时定的」O-28 下那条「`miyu onebot web` 去掉」改成现在的样子，注明 2026-10-10 项目主人定。

**`docs/designs/18-通讯平台.md`** 第三节命令表：`miyu onebot web` 一行照现在的样子写。

### 要定的

| # | 定什么 | 推荐 | 为什么 |
|---|---|---|---|
| 1 | `web` 怎么打开 | 跑旁边的 `miyu web --package onebot`，把它的退出码交回 | 打开网页、登录、找后台页都是网页软件的事，桥不另做一份 |
| 2 | 找不到 `miyu` | 说清楚、退出码 1 | 照说不会：`miyu-onebot` 一直装在 `miyu` 旁边 |

### 不做什么

- 不恢复桥自己的网页、端口、登录。
- 别的包要不要也在自己的命令里放打开页面的子命令：告诉核心，由它定要不要写成约定。

### 验收

### 验收结果（2026-10-10）

**「要定的」两条**：照推荐定（跑旁边的 `miyu web --package onebot`、退出码照它的；找不到 `miyu` 说清楚、退出码 1）。

**施工时定的**（`onebot.md` 第一条「施工时定的」O-28 补，第 173 到 175 条）：

1. `web` 只认不带参数的 `miyu onebot web`，多带的照用法不对；`miyu` 照 `miyu-onebot` 真实位置旁边找（和拉起核心同一个），不连核心、不读数据根；退出码放不进一个字节的、被信号停下的算 1，同 `miyu web` 转给网页软件的写法。跑不了（不在、不让跑）的一句 `web/no-miyu`，带路径和系统说的原因，照系统的语言（第 173 条）。用法 `usage` 加上 `web`。
