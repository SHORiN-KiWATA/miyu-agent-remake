# TUI 配置页

状态：本地验证完成，待三平台 CI 与项目主人验收（2026-10-04）。

## 目的

对话内 /config 和独立 config 启动共用全屏四分页，使用核心现有配置接口管理供应商、模型、默认用途和模型池。

## 蓝图改哪几节

- tui.md「全屏配置页」：布局、按键、草稿与异步 IPC、独立启动、秘密处理与核心待接范围。

## 不做什么

- 不改核心 CLI、温度、供应商显示名、下架清理；8-21 到 8-24 由核心会话完成后适配。
- 不修改已有供应商 ID/池名称，不添加当前未需要的高级配置。

## 验收

- 隔离 MIYU_HOME：独立 config 启动不载入/创建会话；Esc 返回 shell。
- /config 打开四分页；退出保留输入和对话位置；流式输出期间正常编辑。
- 添加供应商、密钥/环境变量、测试、模型全列表、窗口/能力/思考/价格、单模型默认与池成员保存后重读一致。
- 密钥不出现在界面值、调试输出、普通配置和测试样本；失败/版本冲突留草稿，不报告成功。
- 单元与真实端点/伪终端测试、门禁、三平台 CI 全绿，项目主人验收后整理合入 proto/tui-demo。

## 风险

- 多端修改：保存带个人 expect，收到变更重读，编辑草稿保留。
- 未登记配置不写；临时刷新失败不清理模型池。

## 实现与验证记录

- 配置状态与绘制分开；普通配置带个人层 expect，密钥先 secret.set 后 config.set 引用。未确认的请求在失联时明确失败，不重放。
- 本轮只适配启动意图 `--page config`；按职能找软件、选择 terminal-ui 提供者由核心启动器负责，不向未运行的进程发信号。
- 首个独立页 PTY 测试在旧代码失败，15 秒内发现没有配置页；实现后通过。完整价格覆盖和密钥掩码、连接失败原文的回归测试也先红后绿。
- 真实伪终端测试验证独立启动、已有对话返回、文本/视觉默认、成员顺序、单模型窗口和密钥只存秘密文件。测试全部使用临时 MIYU_HOME。
- 验收运行：`~/.cache/miyu-tui-config/try --page config`；对话入口 `~/.cache/miyu-tui-config/try`，再输入 `/config`。隔离目录带原有模型配置和环境变量引用，不复制会话。
- 按键：`[`/`]` 切分页，方向键或 hjkl 移动，Enter 编辑/确认，供应商页 p 测试、a 添加；模型池 Tab/Space 选成员，表单 s 保存、Esc 取消。

- 本地结果：TUI 单元与端到端 681 项通过，11 项量尺/人工测试忽略；格式和 clippy 无警告。根 workspace `cargo xtask check` 八项门禁通过。三平台 CI 在草稿分支运行，真人验收后才合入 proto/tui-demo。

- 最后审查补守：失联/缺主程序显示具体原因；secret.set 失败恢复原引用；读取期间收到变更在结束后再补读；取消全部输入能力恢复继承资料。四项均先用回归测试复现，再修正。

- p 测试在模型栏指定当前模型，供应商栏由核心挑模型；回归测试证明不会选中了 beta 却试 alpha。
