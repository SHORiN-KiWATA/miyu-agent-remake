## 施工单 O-25（上）：出站链

状态：已完成（2026-10-09；只有技术细节，照施工方案第一节第 1 条直接做）。

### 目的

她要说出去的话，现在（O-23 上）照纯文本拆段就发了。这一步让它先过群聊内核的出站链（`chat.md` 第五条，O-10 早就做好、测过）：清掉漏进正文的工具调用、只有空白的、整条括号旁白的；同一回合里不说重复的话；照旧版的规矩决定这一条带不带引用、带不带 @（18 第十节）。群里的命令回执发出 3 秒后撤回。顺手修 O-23 下发现的测试工具小毛病（单独一个提交）。

### 蓝图改哪几节

`docs/blueprint/onebot.md` 第一条「群里怎么叫她」第 8 条（她的回话发回群里）改成：

1. 每一条她的话（群、私聊都一样）先过 `OutChain::builtin().judge(outgoing, &ctx)`：
   - `Outgoing { text, images: [] }`（她的图随后面的步子）。
   - `OutCtx.sent`：这一回合已经发出去的（照这一轮的 `venue.delivered`）。
   - `OutCtx.target`：群里「本来想要」引用这一轮回的那条消息、@ 发它的人（这一轮几条触发的，照最后一条）；私聊两样都是假。
   - `OutCtx.since`：她回的那条之后群里来了几条别人的（不算那个人自己的、不算她的）、过了多少毫秒、群里最后一条是不是她的（照投影）。
   - `OutCtx.outbound`：这个群的 `Params`（`quote_after`、`mention_after`、`min_bigrams`、`similar`、清理的名单）。
2. `Out::Drop(why)`：不发，运行日志记一行原因（`leaked`、`blank`、`aside`、`repeated`）；这一步还没有出站队列，丢了的不另记事件（要定的第 3 条）。
3. `Out::Send { outgoing, target }`：照 `plain`、`split` 拆段；第一段带上引用（OneBot 的 `reply` 段，平台编号）和 @（`at` 段），后面几段不带；照现在的办法发、记 `venue.delivered`。
4. **命令回执**（群里的斜杠命令，O-22）：发出 3 秒后撤回（`delete_msg`，秒数放 `bridge.json`）；撤回失败的记一行运行日志。发命令的那条消息不撤。私聊的回执不撤。

`docs/designs/18-通讯平台.md` 第十节：送达、失败记的事件照现在的名字写（送达是核心的 `venue.delivered`，失败、入队是 `ext.onebot.venues.*`），原来那句 `ext.onebot.venues.delivered` 改掉。

### 要定的（技术细节，照推荐定）

| # | 定什么 | 推荐 | 为什么 | 没选 |
|---|---|---|---|---|
| 1 | 一轮几条触发、回的不是一个人，引用谁 | 最后一条 | 和 `tool.call` 的 `by` 取法一样（她这时在回应的那一条）；一条消息只能引用一条 | 引用第一条；不引用 |

| 3 | 丢掉的记不记事件 | 这一步只记运行日志 | 出站队列（O-25 下）才有入队、失败的事件；先不另起一种 | 现在记 `ext.onebot.venues.*` |

### 验收结果（2026-10-09）

**「要定的」三条**照推荐定：一轮几条触发的引用最后一条（并进来的换成并进来的最后一条）；引用和 @ 只带在第一段；丢了的只记运行日志（`reply dropped why=…`）。

**施工时碰到的一处**（报给主会话、已定）：私聊没有 `venue.delivered`，照它算私聊等于不去重。定成私聊照桥这一轮自己放进写队列的那几条去重（内存里一个会话一份，换回合清，重启丢），是过渡，O-25 下有了入队事件私聊、群都改成照入队算；群里「前一句 NapCat 还没回、下一句已经来了」的前一句不算，也写进施工时定的（第 112、113 条）。

**施工时定的**（`onebot.md` 第一条第 106 到 115 条）：她回的那一条照投影的最后一个触发；丢了的只记一行；引用、@ 只在第一段，@ 后面跟一个空格段；编号、号照原样写成字；`Since` 三格照投影数（序号比先后）；她连着说的后一句照链的规矩带引用；群里这一回合发出去的照 `venue.delivered`；私聊的照桥自己记的（过渡），私聊也照纯文本拆段；回执不过链，群里成了的、被拒的都撤，限流的提示不撤，撤是另起的任务，秒数放 `bridge.json`（`receipt_recall_seconds` 3）；测试的模型替身另写一个（一次回复里能既说话又调工具、能等放行）。
