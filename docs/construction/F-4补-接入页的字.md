## 施工单 F-4（补）：接入页的字

状态：施工中（网页的会话 2026-10-10 当用户在「接入」页走了一遍提出来；叫法照项目主人 2026-10-10 定的，接入QQ 的会话转告；字的写法主会话定）。

### 目的

「接入」页里接入QQ 的四项配置，名字重复了组名，说明里写着 TOML、JSON 的写法，用户照着填会被拒；「自己人」的说明说「在接入QQ的网页上改」，可头里本来就能改（设计 30 第三节：平台接入的配置项在头里单独的「接入」页改）。项目主人同一天把「主人」改叫「终端管理员」，「自己人」改叫「白名单成员」。

### 这一步做什么

1. `resources/packages/onebot.toml` 四项的名字去掉组名，中、英、日一起改：
   - `listen`：端口、Port、ポート；
   - `web`：网页端口、Web page port、Web ページのポート；
   - `token`：令牌、Token、トークン；
   - `trusted`：白名单成员、Whitelist、ホワイトリスト。
2. `token` 的说明删掉 `{ secret = … }`、`{ env = … }` 的写法，生成的参考文件里「能写」那一行照旧写着。
3. `trusted` 的说明删掉 JSON 写法和「在接入QQ的网页上改」，改成「每一项写 qq:QQ号，例如 qq:20017」。说明里讲白名单成员能做什么的那半句照现在的行为留着，接入QQ 的会话改行为时一起改。
4. 核心的 `external.bindings.<external>` 显示名：主人的平台账号改成终端管理员的平台账号，英文 Terminal admin's platform accounts，日文 端末管理者のプラットフォームのアカウント。
5. 蓝图 `protocol.md` 的 `preset.set`：键列表写上 `features.<功能>`，以前的 `software.<包>` 照认（F-3 下就这样了，蓝图漏写）。
