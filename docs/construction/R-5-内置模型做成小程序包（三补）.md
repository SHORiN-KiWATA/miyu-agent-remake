## 施工单 R-5（三补）：内置的语义模型做成小程序包

状态：已完成（2026-10-09 写、合；模型文件的放法、清单的约定、核心照依赖拉、删下载 2026-10-09 核心的主会话点头；方向项目主人 2026-10-09 定：内置的 embedding 做成一个可选的包、只放 bge、模型文件打进包里、出厂不装；包的说法照设计 `30-插件框架.md`（2026-10-09 项目主人定）：它是「小程序」种类（`kind = "worker"`），人格记忆的清单写 `[recommends] workers = ["embed"]`；核心照依赖拉小程序那一段是这一步；碰核心的发核心的主会话看）。原来照 `kind = "embedding"` 写的那一版作废。

### 目的

主程序轻：不背 24 MB 的模型，也不在第一次用时去下。要照意思找、又不想用远程的，装「内置语义模型」这个包，装好就能用、不联网；不装的照关键词，或者指定一家远程的。

### 蓝图改哪几节

- `recall.md` 第四条：第 1 款（本机的那一路从哪来：人格记忆推荐的小程序包 `embed`）、第 2 款（模型清单在包目录里、去掉 `url`）、第 3 款（不下了：第一次用时核对包里的文件）、第 4 款（`miyu-embed` 照小程序的找法）、「在哪」「守着它的」「出处」。
- `packages.md`：内置模型这个小程序包的样子（例子）；包自己的文件放清单旁边的同名目录（写实）。
- `core.md` 第 10 步：照装了的小程序包拼 `Embedder` 要的。
- `config.md`、`protocol.md` 的 `config.schema`：选项多可以没有的 `available: false`（只有核心查得出用不了的才有，头画成灰的、选不了）。
- `store.md`（`generated::Staged` 去掉）、`http.md`（`miyu_http::download` 去掉）：只有下模型在用。

### 定了的

1. **包**（设计 30 第六节）：

   ```toml
   # home/<管理员>/packages/embed.toml（出厂不装）
   [package]
   kind = "worker"
   protocol = [1, 1]
   name = { zh = "内置语义模型", en = "Built-in semantic model", ja = "内蔵の意味モデル" }

   [worker]
   program = "miyu-embed"
   ```

   人格记忆的清单（出厂的 `resources/packages/memory.toml`）多 `[recommends] workers = ["embed"]`：没装照起，只有关键词那一路（或者远程的）。
2. **程序**：照 F-1 的规矩只找 `miyu` 真实位置旁边的（`packages::locate`，不找 `PATH`）。装包时程序放在那里，随装包、发行那一段。
3. **模型的文件**：放在包清单旁边的同名目录（`packages.md` 早写的「包自己的文件放同名目录」，两层都适用：出厂的在资源目录 `packages/embed/`，自己装的在 `home/<管理员>/packages/embed/`；目录照 `miyu_store::packages::Found::files_dir` 算，记忆那边不自己拼）：模型清单是这个目录里的 `model.toml`（核心照这个名字找：内置模型这个小程序认的约定，小程序清单里不另写），模型文件照它的 `name` 在同一个目录里。模型清单去掉 `url`（不下了）。仓库里留一份原本：`crates/miyu-embed/package/embed.toml`、`package/embed/model.toml`（bge-small-zh-v1.5 的大小、SHA-256）；模型文件不进仓库，做包时从 Release `models-bge-small-zh-v1.5` 取。
4. **核心照依赖拉**：拼 `Embedder` 要的那一段是一个能再调的函数（`miyu-core` 的 `embed::setup`，照这时读到的清单）：F-5 装卸当场生效时，装上、卸掉 `embed` 照它当场换（2026-10-09 核心的主会话提醒，项目主人定装卸不重启核心）。现在只在起来读清单那一次调：人格记忆装着、它推荐的 `embed` 也装着（读成了、种类是小程序），`Embedder` 照它拿程序、模型清单、模型目录（就是包目录）。没装的本机那一路没有，记一行 `INFO embedder unavailable reason=no embed package`（出厂不装，这是常态，不是警告）；程序不在、模型清单读不了的照旧 `WARN embedder unavailable reason=…`。
5. **不下了**（项目主人定用内置的包以后不再走的路，随这一步删，2026-10-09 核心的主会话同意）：去掉运行时的下载、写临时文件、下不成一小时重试。删掉的：
   - `crates/miyu-session/src/embed/fetch.rs` 的下载那一半（照清单下、边下边写、超过大小停、一小时重试），留下的核对那一半挪成 `embed/files.rs`；
   - `miyu_store::generated::Staged`（一块一块写、提交了才出现的文件）和它的两条测试：只有下模型在用；
   - `miyu_http::download`（边下边交）和它的测试：只有下模型在用；
   - `miyu_store::resources::ResourceRoot::embed_manifest`、`resources/models/embed/bge-small-zh-v1.5.toml`：模型清单搬进包里（原本在 `crates/miyu-embed/package/`）；
   - 模型清单的 `url` 一格；`EmbedSetup` 的 `cache`、`client`；会话测试 `tests/embed.rs` 里下载的那几条（假服务器给文件、下坏了不留、一小时内不再试、真下 Release 的量尺）。第一次用时在后台照模型清单的 `size`、`sha256` 核对包里的文件：对不上的这一回用不了（`WARN embedding model mismatch file=…`），不删包里的东西（是装的那一方的）。核对着的时候交回「还在备」。装卸要重启核心，没对上的这一回不再试。
6. **没装时「内置模型」不可选**（项目主人说「不可选」；形状 2026-10-09 核心的主会话定）：`config.schema` 的选项多可以没有的 `available`，只写 `false`，核心查得出用不了的才写（现在只有 `local`：本机的那一路没有）。头照它列着、画成灰的、选不了；为什么用不了的那一句头自己写。`models.embedding` 没写时照旧当 `local`，实际只照关键词找。
7. **换模型**：换包，或者指定远程的；`embedding.local` 不做（项目主人定）。

### 不做什么

- 装包、卸包和发行的配方（F-5、W-11 那一段）：开发时照「验收」第 4 条手摆一份。
- 别的本机模型的包：要的时候照同一种再做一个。
- `miyu check` 查包里的模型文件：用到再说。

### 验收

1. 测试先写，没实现时红：
   - 核心：装了 `embed` 的照它拼（程序在主程序旁边、模型清单和目录在包目录里）；没装的、种类不是小程序的、人格记忆没装的没有。
   - 会话那一层（`embed.rs`）：包里的文件齐、对得上的拉起、算得出；对不上的用不了、不删；不联网（没有下载那一条路了）。
   - 仓库里的原本：`embed.toml` 读得成小程序包；`model.toml` 读得成模型清单、没有 `url`。
   - 协议：装了的 `config.schema` 里 `local` 带 `note`、不带 `available`；没装的不带 `note`、带 `available: false`；`off` 都不带。
   - 原来的 `memory_vectors.rs`、`memory_meaning.rs`、`embed.rs` 改成照包目录接上，照旧全过。
2. 手写变异 15 个左右，全被逮住；`cargo xtask check` 全过；三台机器的 CI 和长跑全绿。
3. 合之前把清单、`available` 的改动发核心的主会话看。
