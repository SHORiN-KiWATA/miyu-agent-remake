## 回答的 Markdown：两个头共用的约定

状态：草稿，2026-10-10 主会话起草；终端界面的会话同一天过目，HTML 和本机路径两条照项目主人 2026-09-29 给终端定的改；待网页的会话过目。项目主人同一天定：核心只交 Markdown 原文（条目 `reply` 的 `text`），解析和渲染都归头；两个头照这一页解析，同一段字理解成一样的东西。这一页只管「认成什么」，不管「画成什么样」：颜色、字体、折行、高亮、卡片的样子各头自己定。

### 是什么

AI 的回答是 Markdown 原文，流式时一段段接上来（`view.append`）。终端界面用 `pulldown-cmark`，网页是自己写的解析器，两边各自解析。这一页列出两边必须一致的地方。没写到的照 CommonMark。

### 认哪些写法

1. 基线是 CommonMark，加 GFM 的表格、删除线（`~~`）、任务列表（`- [ ]`、`- [x]`）、自动链接（裸写的 `https://…`）。
2. 标题只认 `#` 开头的；下划线式（文字下面一行 `===`、`---`）也认，照 CommonMark。
3. 代码块：
   - 围栏用三个以上的反引号或波浪号；语言取信息串的第一个词，转成小写。
   - 语言是 `mermaid` 的交给画图（终端栅格化，网页用画 mermaid 的软件包）；没装画图的照代码显示。
   - 没写语言的照纯文本，不猜语言。
   - 缩进四格的代码块也认。
4. 公式：
   - 行内 `$…$`、`\(…\)`；块 `$$…$$`、`\[…\]`（块的定界符可以和公式写在同一行，也可以各占一行）。
   - `$` 当行内公式要同时满足：开头的 `$` 后面不是空白，结尾的 `$` 前面不是空白、后面不是数字。所以「花了 $5 和 $10」不是公式。
   - 反斜杠转义的 `\$` 是一个普通的美元符号。
   - 公式写错、画不出来的，照原文显示，不报错、不吞字。
5. HTML（照项目主人 2026-09-29 给终端定的，终端蓝图 `tui.md`「正文」第 12 条、「图片、公式和 mermaid 图」第 8、9 条）：
   - 照 Markdown 的样子认：`<b>`、`<strong>` 粗体；`<i>`、`<em>` 斜体；`<u>` 下划线；`<s>`、`<del>`、`<strike>` 删除线；`<code>`、`<kbd>` 行内代码；`<mark>` 高亮；`<sub>`、`<sup>` 下标、上标；`<a href>` 链接；`<hr>` 分隔线；`<br>` 换行。
   - `<p>`、`<div>`、`<center>`、`<section>` 去掉外壳自成一块，`<center>` 和 `align="center"` 居中；`<span>`、`<font>` 去掉标签只留字。
   - `<details>`（带 `<summary>`）认成可以收起的一块。
   - `<img>` 当 `![alt](src)`，写了 `width`、`height` 照它。
   - 行内的 `<svg>` 收成一张图，不读外面的东西。
   - 别的标签（`<table>`、`<ul>` 这些）照原文显示：不执行、不隐藏、不当成格式。注释 `<!-- -->` 不显示。
   - 「认成什么」两个头一样；画不了的照原文显示。
6. 链接和图片：
   - `http`、`https` 的照链接；单独占一行的图片、音视频地址，头可以画成卡片。
   - 本机路径（绝对路径、`~/` 开头、`file://`）两个头认法一样：图片当图片，链接当链接。终端和核心在同一台机器上，照本机画图、链接能点开用系统打开（项目主人 2026-09-29 给终端定的，终端蓝图「图片、公式和 mermaid 图」第 3 条）；网页等核心认路径那一步（以后另拆），在那之前照文字显示。
   - 别的协议（`javascript:` 这些）照文字显示，不做成链接。

### 流式时半截的怎么算

回答还在写（条目 `open: true`）时，最后一段可能没写完。两个头照下面的规则补，补的字只用于显示，不改原文。

1. 没收尾的代码围栏：当作在末尾收了尾，代码照写到哪显示到哪。`mermaid` 没收尾之前照代码显示，收了尾才画图。
2. 表格：出了几行画几行；表头下面的分隔行还没到的，先照普通段落显示。
3. 最后一段里成单的反引号、`**`、`__`、`~~`：先当普通字显示，配上对了再当格式。
4. 公式的定界符没收齐：照原文显示。
5. `<details>` 没收尾：照展开着显示。
6. 写完以后（条目 `open` 没了）照整段重新解析，以写完的为准。

### 不认的

不认的写法照原文显示，一个字都不吞。拿不准的时候宁可照原文，不要猜成格式。
