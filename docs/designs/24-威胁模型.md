## 威胁模型（草案）

状态：T1、T2 已定（2026-09-25）。其余内容为草案。

安全相关的话散在 `04`、`06`、`07`、`11`、`18`、`21` 里。外部读者说拼不出「每个对手由谁挡、挡在哪一层、挡不住会怎样」。这一份把它们收成一张表。加新功能时，先看它碰到了表里的哪一行（T1）。

### 一、几条总的规矩

- 权限由代码判定，提示词里的任何文字都不授予权限（`06-多用户与身份.md` 第五节）。
- 身份取自连接，不取自正文；代表别人只能降权（`04-核心协议.md` 第四节）。唯一的例外是主人绑定（`18-通讯平台.md` Q7）。
- 沙盒管得住的不问人，要越过沙盒的才问人（`11-权限与沙盒.md` A1）。
- 可信的字段和不可信的字段分开承载，不可信的文字进请求之前一律转义（`08-上下文投影.md` C7）。
- 安全的默认值不因方便放宽。接受一条风险，要写明是谁、在哪天接受的（T2）。

### 二、对手与防线

| 对手 | 想做什么 | 谁挡、挡在哪 | 挡不住时 |
|---|---|---|---|
| 本机的其他系统用户 | 连上核心、读数据根 | 套接字放在只有本人能进的目录，连接还要出示本机令牌；密钥文件只有本人可读（`04-核心协议.md` 第二节、`07-存储.md` 第九节） | 对方有 root，就什么都挡不住 |
| 沙盒里的命令 | 读密钥、连核心冒充本人、写会在沙盒外执行的文件、把数据发出去 | 读写都是白名单；连不上 Unix 套接字，读不到本机令牌；`.git` 的钩子只读；网络只经代理、按网站放行；环境变量走白名单（`11-权限与沙盒.md` 第四节、第五节） | 越界的事要人确认，人点了同意就放行 |
| 被提示注入的模型 | 调危险的工具 | 权限按这一步是谁要求的来判；工具执行前的链最严者胜；沙盒；越界问人（`05-内核接口.md` 第五节、`11-权限与沙盒.md` 第二节） | 人在确认时随手同意 |
| 恶意扩展、别人写的 MCP 服务器 | 越权、偷数据、在账号之间串数据 | 扩展能力按清单批准；在沙盒里跑，按账号各一份；独占插槽不对外开放；读原始事件要 `events.read`（`05-内核接口.md` 第三节、I3、I5） | 批准过的扩展能力被滥用 |
| 群里的陌生人（外部身份） | 碰主机、探内网、套出别人的私事、刷花费 | 群里没有碰主机的工具；联网工具拦本机、内网和元数据地址；私下说的按听众过滤；限流（`11-权限与沙盒.md` 第三节、第四节，`17-记忆.md` L6，`18-通讯平台.md` 第五节） | 公开说过的话，她可能在别处提起（`17-记忆.md` L5，有意如此） |
| 被盗的主人 QQ 号 | 在私聊里以主人的身份用这台机器 | 所有操作都记在日志里（`18-通讯平台.md` 第三节） | 这台机器在主人的权限级别下被别人用（已接受，第三节） |
| 被拿下或不怀好意的 OneBot 实现 | 伪造主人的私聊 | 默认只接本机的实现，并且要带访问令牌（`18-通讯平台.md` 第三节） | 伪造成功，就和盗号一样（已接受，第三节） |
| 别人写的仓库 | 用项目配置放宽权限，或者把默认模型指到别的地址 | 项目配置只能收紧，只能从已经配好的模型里挑；第一次遇到要信任，内容一变再问（`14-配置.md` G3） | 人信任了一份恶意的配置，它也只能收紧 |
| 同一局域网、公网上的人 | 登录核心 | 默认只听本机；远程访问要手动开，必须登录；密码用 argon2id；失败限流；检查 Origin（`04-核心协议.md` P6、`06-多用户与身份.md` U4、`21-网页.md` 第七节） | 弱密码 |
| 产物和第三方页面 | 拿到登录状态、直接调核心 | 放在沙盒 iframe 里，单独的内容安全策略，只能经受限的通道说话（`21-网页.md` X7） | 受限通道开得太宽（`21-网页.md` 后续再定） |
| 软件源投毒 | 装进恶意的包 | 官方源签名；第三方源要人明确信任；锁文件记哈希；安装前显示申请的扩展能力（`12-进程形态与分发.md` R6） | 人批准了一个恶意的包 |
| 管理员（对成员而言） | 看成员的会话 | 在 Miyu 里看不到：任何管理能力都不越过属主权限（`06-多用户与身份.md` U2） | 管理员直接读磁盘。注册时就如实告诉成员（`06-多用户与身份.md` 第六节） |

### 四、决定

**T1. 威胁模型是一张活表**

- **已定：加新功能、新工具、新场所时，先对照第二节，看它碰到了哪一行；碰到了，就把防线和挡不住的情况补进表里。**
- 重开条件：无。

**T2. 接受的风险要留名**

- **已定：接受一条风险，写明是谁、在哪天、为什么接受；安全的默认值不因方便放宽。**
- 重开条件：无。
