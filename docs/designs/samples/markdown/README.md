## 回答的 Markdown：两个头共用的样例

图纸 `docs/blueprint/markdown.md`。一个 `<名字>.md` 是输入，同名的 `.json` 是「认成什么」的一棵树：块的数组，节点照图纸「还没有的」一节的那一套。两个头的测试各自把解析结果转成这棵树，和 `.json` 逐字比。

比之前两边都这样归一：

1. 相邻的 `text` 并成一个；空的 `text` 不要。
2. 公式（`math`）的字去掉首尾空白；代码块（`code`）的字照原样，末尾带换行。
3. 没写语言的代码块 `lang` 是 `null`；有序列表写 `start`，无序的不写；任务列表的项写 `task`（`true` 做完、`false` 没做），别的项不写。
4. 表格 `table` 的 `align` 一列一个（`left`、`center`、`right`、`null`），`rows` 是一行一个、一格一个行内数组，第一行是表头。
5. `details` 的 `summary` 是行内数组，`children` 是块数组。
6. 不认的协议（`javascript:` 这些）只留链接上的字，不留地址。照原文显示的标签是 `html_raw`，一个标签一个。HTML 注释什么都不留。

2026-10-10 主会话照定稿的约定写的第一批。哪一份和约定对不上、或者两边认得不一样，改约定或者改样例，两头一起改。
