## 网页（草案）

状态：X1 到 X8 已定（2026-09-25）。其余内容为草案。

### 一、它是什么

- 网页是一个头（`01-架构.md` 第五节）：连上核心，订阅视图流，照着条目画，把点击和输入变成命令。它不写业务逻辑，显示什么由核心的视图投影决定（`04-核心协议.md` P3）。
- **以旧版网页为底**（X1，2026-09-25 确认）：样子、版面、交互照旧，数据层照新协议重写。
- 页面由核心里可选的 HTTP 模块提供，只有开了网页才构造它（`04-核心协议.md` P5）。页面文件放在资源目录里，不编进二进制（`12-进程形态与分发.md` R3）。
- 默认只能在本机打开；远程访问要手动开，并且必须登录（`04-核心协议.md` P6）。
- 桌面程序第一版不做，由网页替代（`01-架构.md` 第一节）。也不做「装成应用」（X8，2026-09-25 确认）。

### 二、从旧版带过来什么，扔掉什么

旧版网页一共 4.2 万行：`app.js` 一个文件 13,887 行，样式 11,464 行，手抄的设置字段表 3,501 行。

| 带过来 | 扔掉或改掉 |
|---|---|
| 版面：侧栏、时间线、设置、手机版 | `app.js` 这个上帝文件：按功能拆成小模块，每个文件有行数上限 |
| 时间线的样子（第四节） | 网页自己算时间线：交给核心的视图投影，网页只照着条目画 |
| 主题：MD3 的颜色体系，出厂的晨光、夜阑两套，跟着壁纸取色 | 手抄的设置字段表：设置页照配置清单生成（`14-配置.md` G1） |
| 划词解释与翻译、链接卡片、图片灯箱、代码高亮、diff | 每个仪表盘各拼一套数据：统一走协议的查询 |
| 各个仪表盘的内容 | 编进二进制：改一行页面就要重新编译 |

- 那份手抄的字段表，是从终端设置页的中文字符串里抽出来的第二份，运行时改了字段的位置，它没跟上。这正是配置文档里「一份清单」要治的病（`14-配置.md` 第二节）。

### 三、技术路线

- **原生 JavaScript，按 ES 模块组织；不用框架，不用构建**（X2，2026-09-25 确认）。打包时不需要 Node，旧版的小部件大多能直接搬过来。
- **类型从协议生成**：协议的结构只在 Rust 类型里定义一次，由它生成类型声明文件（`04-核心协议.md` 第二节）。网页的源码用 JSDoc 标注类型，编辑器里照样有补全和类型检查；持续集成里跑一遍类型检查，但它不进发行包。
- **每个文件有行数上限**，由检查守住。旧版的 `app.js` 就是这样一点点长大的。
- **按页面按需加载**：设置、仪表盘、产物查看器这些，用到时才加载对应的模块（`00-设计理念.md` 第一节：谁用谁付）。
- 结构：

| 模块 | 做什么 |
|---|---|
| 连接 | 一条 WebSocket；断了就重连，重连后拿新快照（`04-核心协议.md` 第七节） |
| 视图仓库 | 每个打开的会话一份，按 `view.add`、`view.update`、`view.append`、`view.remove` 更新 |
| 条目的画法 | 每种视图条目一个模块：用户消息、回复、思考、工具、收缩行、提问、确认、子代理、通知（`04-核心协议.md` 第五节） |
| 页面 | 对话、设置、各个管理页，一个页面一组模块 |
| 小部件 | 划词菜单、链接卡片、灯箱、代码高亮、diff、Markdown 渲染 |

- **展开、收起、滚动位置这类纯界面的状态留在网页里**，不回传核心（`04-核心协议.md` P3）。同一个会话开在几个标签页、几台设备上，看到的内容一样，各自展开各自的。

### 四、时间线

沿用旧版网页的样子（X3）。它是一条条跟项目主人对过的：

- 一条 1px 的细线穿过图标那一列，在图标处断开；她开口说话，线就断开。
- 过程默认收起成一行摘要；正在进行的那一段不收。摘要用英文，和终端里一样（`13-终端界面.md` H3）。
- 工具一行：图标、名字、等宽字体的对象，用时紧跟在后面。任何东西都不推到最右边。
- 失败：整行变红，线的颜色不变；展开的详情用一圈细边框。
- 思考一行：原子图标、「已思考」、最后一小段的摘要。
- 她的回复不加气泡；你的消息用一层浅底；不显示时间。
- 行高 30px；次要文字的颜色是正文色和背景色按六四开混出来的。
- 动画：一条缓出的曲线，淡入约半秒，展开约 0.4 秒，位移不超过 4px。

**否决过的，别再提**：

- 每种工具一种颜色的标签；
- 2px 的实线；
- 面板底色，加上运行中的描边；
- 一个回合一整块，把中间说的话也吞进去；
- 什么都拍平成一样的行（项目主人：「完全是灾难」）；
- 标题随工具变来变去；
- 花哨的进度条、光带、脉冲；
- 重复的「Thinking…」标题；
- 光秃秃一个「Worked」，后面没有用时。

### 五、页面

**对话**：

- **侧栏**：会话列表。新建会话时选人格、预设和记忆的范围（`16-人格与预设.md` 第六节）。
- **时间线**：第四节。长会话只画看得见的一段附近，往上翻时再用 `view.page` 取更早的（`04-核心协议.md` 第七节）。
- **输入框**：附件、听写的麦克风按钮（`20-语音.md` 第五节）、斜杠命令的补全（命令目录来自核心，`04-核心协议.md` P4）。
- **确认和提问**出现在输入框上方；**会话树**（主会话、子代理、后台命令）列在输入框下方。概念和终端界面一样（`13-终端界面.md` H4、H7），样子按网页来。
- **右侧面板**：产物，以及会话的信息：上下文用量、待办、改动的文件。

**管理**：

| 页面 | 管什么 | 设计在哪 |
|---|---|---|
| 设置 | 全部配置项，照配置清单生成，可以搜索 | `14-配置.md` |
| 模型与供应商 | 接入向导、池的编辑器 | `15-模型与供应商.md` |
| 人格与预设 | 新建、以谁为底、同名覆盖 | `16-人格与预设.md` |
| 记忆 | 看、搜、改、删，三种清空 | `17-记忆.md` |
| 通讯平台 | 场所列表、每一项属性来自哪条规则、场所总览 | `18-通讯平台.md` |
| 知识库 | 添加文档、挂目录、看索引的进度 | `19-知识库.md` |
| 语音 | 麦克风、她的声音、唤醒词 | `20-语音.md` |
| 软件 | 装了哪些软件、在哪些预设里打开 | `12-进程形态与分发.md`、`16-人格与预设.md` |
| 工具 | 每件工具全量、存根还是关，怎么分组，描述怎么写；最上面一根预算条，每件和每组的 token、调用与加载次数 | `25-工具加载.md` 第六节 |
| 用量 | 各会话、各模型的用量；金额算得准才显示 | `15-模型与供应商.md` 第八节 |
| 账号与权限 | 只给管理员：成员、组、邀请、能力 | `06-多用户与身份.md` |

- **软件包可以带自己的页面**，在清单里声明。旧版的几个仪表盘，比如记账、表情包，就是这样带进来的。第三方写的页面放在沙盒的 iframe 里，只能经一条受限的通道和核心说话（X7）。
- **第一次打开**：和别的头一样只问两件事，接入模型（`15-模型与供应商.md` 第七节）、选人格（`12-进程形态与分发.md` 第七节）。成员第一次登录时选人格，写下「希望 AI 怎么认识你」（`06-多用户与身份.md` 第六节）。
- **手机**：同一套页面，按屏幕宽度排版。旧版专门为手机调过样式。

### 六、主题与语言

- 颜色用 MD3 的语义色。核心按一个种子色生成整套色板（`04-核心协议.md` P3 的 `theme.get`），网页把它映射成 CSS 变量。出厂两套：晨光（暖奶油底、紫藤色）、夜阑（暮蓝底、雾蓝色，默认）。
- 跟着壁纸取色：由一个软件包从壁纸取种子色。旧版靠 matugen 生成一份 CSS 覆盖。
- 界面文字都在资源文件里（`00-设计理念.md` 第六节）；语言跟着这个人的界面语言设置。

### 七、安全

- **本机打开**：`miyu web` 打开浏览器，带着一次性的登录链接，用过就换成登录令牌。旧版在本机不设密码谁都能进，而浏览器读不到本机令牌（`11-权限与沙盒.md` 第五节），所以用这条链接证明是你（X6）。
- **远程**：必须登录（`06-多用户与身份.md` U4）。核心检查 WebSocket 的 Origin 头，防止别的网站连进来（`04-核心协议.md` 第二节）。
- **产物和第三方页面**放在沙盒的 iframe 里，有单独的内容安全策略，碰不到会话和登录状态（X7）。旧版踩过：浏览器的私有网络访问限制，会比内容安全策略先一步拦下产物里的请求。
- **麦克风**：浏览器只在本机或 HTTPS 下给麦克风。远程用听写，要经过带证书的反向代理。

### 八、旧版踩过的坑

| 坑 | 现象 |
|---|---|
| Safari 里给滚动容器设了 `container-type`，滚动位置会被清零 | 页面一直抖 |
| 两个标签页同时删掉最后一个会话，各自兜底新建一个 | 冒出两个新会话。新版命令由核心说了算，多个头发同一件事只生效一次（`04-核心协议.md` 第六节） |
| 换会话时，用量的基线只升不降，没按会话清 | 换过去的会话显示着上一个会话的累计 |
| 私有网络访问的限制比内容安全策略先生效 | 产物里的图表请求被拦下，报错却指向内容安全策略 |

### 九、决定

**X1. 底子**

- **已定：以旧版网页为底，样子、版面、交互照旧，数据层照新协议重写，显示逻辑交给核心（2026-09-25 确认）。**
- 未选 A：移植 dsh 的前端。约 17 万行 React，和「轻量」冲突，数据层也一样要重写。
- 未选 B：从头另写一套。旧版一条条对过的样子要再对一遍。
- 重开条件：无。

**X2. 技术路线**

- **已定：原生 JavaScript，按 ES 模块组织，不用框架、不用构建；类型从协议生成，用 JSDoc 标注；每个文件有行数上限（2026-09-25 确认）。**
- 未选 A：Preact 加 TypeScript。组件化，但要构建，界面层也要照旧版的样子重写一遍。
- 未选 B：React 加 TypeScript。最重。
- 重开条件：实测原生写法让某个页面复杂到改不动。

**X3. 时间线**

- **已定：沿用旧版网页的样子和否决清单。**
- 重开条件：项目主人另有决定。

**X4. 设置页**

- **已定：照配置清单生成，可以搜索；模型池、供应商接入这几样复杂的，用专门的编辑器（`14-配置.md` 第九节）。**
- 未选：手写每一页。旧版就是这样，字段表手抄了一份，和终端设置页、运行时各说各的。
- 重开条件：无。

**X5. 页面文件放在哪**

- **已定：放在资源目录里，由核心的 HTTP 模块提供，不编进二进制。**
- 未选：编进二进制，也就是旧版的做法。改一行页面就要重新编译。
- 重开条件：无。

**X6. 本机怎么证明是你**

- **已定：`miyu web` 打开一条一次性的登录链接，用过就换成登录令牌；远程必须用账号密码登录。**
- 链接 5 分钟内有效、只能用一次（初值）。令牌放在网址 `#` 的后面，不会发给服务器，也不进 Referer；页面拿到以后立刻从地址栏抹掉（2026-09-25 补）。
- 未选：本机不设防，也就是旧版的做法。同一台机器上的任何程序，包括沙盒里的命令，都能打开网页冒充你。
- 重开条件：无。

**X7. 产物和第三方页面**

- **已定：放在沙盒的 iframe 里，单独的内容安全策略，只能经受限的通道和核心说话。**
- 未选：和网页同源地跑。第三方的页面就能拿到你的登录状态。
- 重开条件：无。

**X8. 装成应用**

- **已定：不做（2026-09-25 确认）。**
- 未选：做一份网页应用清单，能从桌面和手机主屏的图标打开。
- 重开条件：有人需要。
