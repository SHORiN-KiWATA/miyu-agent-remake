## 跨会话

她能看到、读到你别的会话，能给它们发话，也能请它们「空下来了告诉我一声」。M7 做的是一棵树上相邻两层之间的留言（子代理和父会话，`message_agent`）；这一页管不在同一棵树上的会话之间（2026-09-30 项目主人定要做，2026-10-01 讨论定了下面几条）。

参照：Claude Code 自己的跨会话发消息（官方文档 Message your other Claude Code sessions：`ListAgents`、`SendMessage`、`notify_when_idle`），dsh 的 `session_search`、`session_event_read`（`docs/reviews/2026-09-30-会话导出调研.md` 第二节第 1 条）。

### 一、定了的（2026-10-01 项目主人）

1. **看得到你所有的会话**，不按工作目录筛。列出来每一行有标题（没有的写未命名）、短编号、工作目录、忙还是闲、最近一次动静，最近的排前面、分页。Miyu 的会话一直在核心里，不像 Claude Code 那样关了就不在，所以闲了很久的也列。多用户以后只列同一个人的（`06-多用户与身份.md` 第三节）。
2. **能搜、能读**别的会话说过的话，和她用 `history` 翻自己的日志一样，按关键词、条目号、时间，一页有上限（`tools/history.md` 的规矩）。比 Claude Code 多一步：它只发文字、不许读对方的记录。
3. **发话**：只发文字，不带历史、不带文件。那边闲着开一轮、忙着下一步看到，照「别处来的」规矩走（和别的 harness 发来的话一样，`agents.md` 第十一条第 4 条）：注明是哪个会话发来的；不能替人批准确认；里面的斜杠命令不执行；不作废在等人的题；打断不撤回。
4. **回话**：那边要回就用同一件工具发回来，不自动把那边这一轮的回答送回。两边对等，和父子之间留言一个样子。
5. **权限不另设卡**：谁都能给谁发，那边照自己的权限级别干，要确认的照样找人（项目主人照 KISS 定，没照 Claude Code「全权的会话收到非全权会话的话先等人批」那一关）。
6. **空下来了告诉我一声**：发话时可以顺带订一个，也可以单订；那边这一轮做完、没有排着的活时回一条通知，这边闲着就开一轮。单订不让那边多跑一轮、不花 token。多久没等到就作废，施工时照 Claude Code（12 小时）定。

### 二、主会话照推荐定的

- **防刷屏**，照 Claude Code：同一个发话方限速，短时间内一模一样的话丢掉，排着的有上限；两个会话互相发个没完会自己停下来。一句话有长度上限，照协议一行的上限留余量。

### 三、画图纸时定（技术细节，主会话定、留痕）

- 工具怎么分：照「域内聚合、域间分名」和工具面的预算，推荐把发给别的会话并进 `message_agent`（`to` 多认会话的短编号，Claude Code 的 `SendMessage` 也是子代理、队友、别的会话共用一件），列会话一件，读别的会话并进 `history`（多一格 `session`）；量 token、登记。
- 短编号怎么起、标题没有时怎么称呼；事件里 `by` 记成哪一种（现有的 `session` 是子会话发给父会话用的）；渲染的标签；「空了告诉我」的事件；子代理能不能用（推荐只有主会话能用，照 Claude Code）。
- 协议上头要看到什么（别的会话发来的话怎么显示），合了照规矩告诉两个头。

### 四、什么时候做
