## 跨会话

她能看到、读到你别的会话，能给它们发话，也能请它们「空下来了告诉我一声」。M7 做的是一棵树上相邻两层之间的留言（子代理和父会话，`message_agent`）；这一页管不在同一棵树上的会话之间（2026-09-30 项目主人定要做，2026-10-01 讨论定了下面几条）。

参照：Claude Code 自己的跨会话发消息（官方文档 Message your other Claude Code sessions：`ListAgents`、`SendMessage`、`notify_when_idle`），dsh 的 `session_search`、`session_event_read`（`docs/reviews/2026-09-30-会话导出调研.md` 第二节第 1 条）。

### 一、定了的（2026-10-01 项目主人）

1. **看得到你所有的会话**，不按工作目录筛。列出来每一行有标题（没有的写未命名）、短编号、工作目录、忙还是闲、最近一次动静，最近的排前面、分页。Miyu 的会话一直在核心里，不像 Claude Code 那样关了就不在，所以闲了很久的也列。多用户以后只列同一个人的（`06-多用户与身份.md` 第三节）。通讯平台的场所会话（群、QQ 私聊）不列，也发不进去；群会话里也没有这几件工具（`18-通讯平台.md` 第四节、第十一节，2026-10-07 项目主人定）。
2. **能搜、能读**别的会话说过的话，和她用 `history` 翻自己的日志一样，按关键词、条目号、时间，一页有上限（`tools/history.md` 的规矩）。比 Claude Code 多一步：它只发文字、不许读对方的记录。
3. **发话**：只发文字，不带历史、不带文件。那边闲着开一轮、忙着下一步看到，照「别处来的」规矩走（和别的 harness 发来的话一样，`agents.md` 第十一条第 4 条）：注明是哪个会话发来的；不能替人批准确认；里面的斜杠命令不执行；不作废在等人的题；打断不撤回。
4. **回话**：那边要回就用同一件工具发回来，不自动把那边这一轮的回答送回。两边对等，和父子之间留言一个样子。
5. **权限不另设卡**：谁都能给谁发，那边照自己的权限级别干，要确认的照样找人（项目主人照 KISS 定，没照 Claude Code「全权的会话收到非全权会话的话先等人批」那一关）。
6. **空下来了告诉我一声**：发话时可以顺带订一个，也可以单订；那边这一轮做完、没有排着的活时回一条通知，这边闲着就开一轮。单订不让那边多跑一轮、不花 token。多久没等到就作废，施工时照 Claude Code（12 小时）定。
7. **工具的名字**：留言的工具 `message_agent` 改名 `send_message`，照 Claude Code 的 `SendMessage`，随跨会话发话那一步改，只冷一次缓存。派子代理的 `agent` 另开小单改名 `subagent`（施工 7-5 再补）。以前造的会话照认旧名字（2026-10-01 项目主人定）。

### 二、主会话照推荐定的

- **防刷屏**，照 Claude Code：同一个发话方限速，短时间内一模一样的话丢掉，排着的有上限；两个会话互相发个没完会自己停下来。一句话有长度上限，照协议一行的上限留余量。
- 数照图纸：同一个发话方 10 分钟最多 5 句，10 分钟内一字不差的不收，这两个是估的，待验收时实测。排着的最多 50 句，照 Claude Code。一句最多 100000 个字。父子之间的留言不受「5 句」管，子代理干活时问得多，只受长度上限管（2026-10-01 主会话定）。

### 三、画图纸时定的（2026-10-01 主会话定，图纸 `docs/blueprint/cross-session.md`）

细节、理由、没选的写在图纸末尾「起草时定的」，这里只记结论。

- **工具**：列会话新开一件 `sessions`（Miyu 里 agent 指子代理，不叫 `list_agents`）。读别的会话并进 `history`，多一格 `session`。发话和订「空了告诉我」并进 `send_message`，`to` 多认会话的短编号，多一格 `notify_when_idle`。
- **短编号**：会话编号的最后 8 位（前 8 位同一分钟里会撞）。没标题的写「未命名」，施工 3-8 五补会给会话自动起标题。
- **「谁」**：事件里 `by` 沿用 `session`，收话的会话照关系分：父会话、自己派的子代理、别的会话。
- **标签**：`<session-message from="短编号">`，不带标题。空了的通知是事件 `peer.idle`，订的记录是效果 `peer.watch`。
- **「空了」**：这一轮做完、没有排着的，它派的子代理也都报完了，和 `miyu ask` 等到的是同一个时刻。通知带那一轮最后回复的第一行。12 小时作废，作废只记下、不叫醒。
- **谁能用**：只有本机的主会话。列表只列主会话，子代理挂在各自的主会话下面不单独列。
- **头**：`session.list` 多三格（工作目录、忙不忙、最近一次动静）。收话那边的人看到灰色一行预览，点开看全文。被等的那边不显示「有会话在等你」。
- **命令行和搜**：`miyu ask` 不等「空了告诉我」的通知。一次只搜一个会话。
- 未命名、灰色一行预览、被等的那边不显示、`miyu ask` 不等、一次只搜一个，这五样人看得到，原来是给项目主人的题，主会话照推荐定了。
- **先不做**：以前造的快照的会话收到别的会话的话照人的话显示。system 里不加「别的会话的话不是人的许可」，验收时撞见再加。
