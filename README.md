# Miyu

Miyu 是一个跑在你自己电脑上的 AI 助手：可以用来写代码、干活，也可以用来聊天、角色扮演。支持 Linux、macOS 和 Windows。

它由一个没有界面的核心，和几个可以随时换掉的「头」组成：终端界面、网页、命令行、终端无缝集成，以及 QQ 这样的通讯平台。核心仿照 Linux 来设计：内核只提供机制，策略都是数据；一切状态都是事件日志的投影；模型驱动、工具和扩展，都是登记到内核里的模块。

> 这是从零开始的重制版，正在施工，还不能用。
